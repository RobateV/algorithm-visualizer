# 术语规范

> 目的：全站统一用词。**只收录已从原书核对过的术语**；未读章节的术语先列「待补」，不预先定义。

## 1. 使用规则

1. 页面文案优先使用本表「原书术语」列。
2. 同一概念只保留一个主词，其余写进「常见别名」，不另起新词。
3. 标注 `[BOOK]` 的定义必须附页码；`[DERIVED]` 需说明依据。
4. 术语一旦确定，跨章节复用，不在各章重复定义。

## 3. 已确认术语（0x04 二分）

| 原书术语 | 定义 | 常见别名 | 易混概念 | 来源 |
| --- | --- | --- | --- | --- |
| 后继 | 单调递增序列中「≥ x 的数中最小的一个」 | 下界、lower_bound 语义 | 前驱；注意与「后继节点」的树论含义不同 | `[BOOK] p.26` |
| 前驱 | 单调递增序列中「≤ x 的数中最大的一个」 | 上界、upper_bound 语义 | 后继 | `[BOOK] p.26` |
| 闭区间二分 | 始终保证答案落在闭区间 `[l, r]` 内、以 `l = r` 结束的写法 | 本书二分写法 | 左闭右开 `[l, r)` 写法（站点教学页采用，非本书） | `[BOOK] p.26` |
| 单峰函数 | 有唯一极大值点，左侧严格单调上升、右侧严格单调下降的函数 | — | 单谷函数 | `[BOOK] p.28` |
| 单谷函数 | 有唯一极小值点，左侧严格单调下降、右侧严格单调上升的函数 | — | 单峰函数 | `[BOOK] p.28` |
| 三分法 | 通过取两个分点把定义域分三段、比较函数值来缩小极值点所在区间的算法 | ternary search | 二分法 | `[BOOK] p.28` |
| 二分答案 | 把「求最优解」转化为「判定某值是否可行」并二分分界点的做法 | 二分答案转判定 | 二分查找（在序列中找元素） | `[BOOK] p.28` |

### 2.1 需要特别区分的两组词

1. **「二分查找」vs「二分答案」**
   - 前者在**有序序列**中定位元素 `[BOOK] p.25–26`；
   - 后者在**答案值域**上二分，核心是判定函数的单调性 `[BOOK] p.28`。

2. **「本书闭区间写法」vs「左闭右开写法」**
   - 本书通篇固定使用闭区间 `[l, r]`、`l = r` 结束 `[BOOK] p.26`；
   - 站点教学页 `binary-search.html` 的 lower_bound/upper_bound 演示使用左闭右开 `[l, r)`。
   - 两者都正确，但**不可混用**；页面文案必须声明当前采用哪一套。
