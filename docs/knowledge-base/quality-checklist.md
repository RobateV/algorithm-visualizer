# 质量检查清单

> 每章完成后逐项自检；`chapter-status.md` 中「已复核」要求全部勾选。

## A. 完整性

- [ ] 章节编号、名称与原书目录一致（含大小写，如 `0x3A`）
- [ ] 页码范围正确（印刷页 ↔ PDF 页换算无误）
- [ ] 原书该节的小标题全部覆盖，无遗漏
- [ ] 书中给出的定理/性质/复杂度结论均已登记
- [ ] 书中代码片段均已收錄或明确说明「书中未给出完整代码」
- [ ] 例题/练习已登记（数量与书中一致）

## B. 准确性

- [ ] 每个结论都有 `[BOOK] p.XX` 或 `[DERIVED]` 标注
- [ ] 公式已对照页面图像复核（不依赖 OCR）
- [ ] 代码已对照页面图像复核，缩进与符号正确
- [ ] 复杂度分析与书中一致
- [ ] 术语使用与 `terminology.md` 一致
- [ ] 未把外部知识写成 `[BOOK]`

## C. 可追溯性

- [ ] `source-map.md` 已新增对应条目
- [ ] 存疑处已记入 `source-map.md` §5
- [ ] 引用页码为印刷页，换算关系正确

## D. 结构化

- [ ] 九个小节齐全（基本信息/定位/知识点/推导/代码/例题/易错/关联/教学建议）
- [ ] 「算法推导」保留了书中思考顺序，而非只给结论
- [ ] 「知识关联」区分了明确/推断/待确认
- [ ] 「教学应用建议」明确标注为非原书内容

## E. 索引同步

- [ ] `concept-index.md` 已登记本章概念
- [ ] `dependency-map.md` 已登记本章依赖
- [ ] `book-outline.md` 中本章状态已更新
- [ ] `chapter-status.md` 中本章状态已更新

## F. 已知风险（全书通用）

- [ ] 扫描件 OCR 的汉字间距已处理
- [ ] 易混字已人工确认（己/已、襯/补 等）
- [ ] 数学符号（≤、≥、−、×）已目视确认
- [ ] 代码中的位运算符未被 OCR 破坏
