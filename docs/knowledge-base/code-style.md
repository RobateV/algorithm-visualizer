# 竞赛代码风格规范

> 依据：目前仅逐行核对了 **0x04 二分（p.26）** 的代码。
> 其余章节的代码风格待读到后再补充——不预先假定全书统一。

## 1. 已观察到的书中风格（0x04）

来源：`[BOOK] p.26`，已对照页面图像逐字符核对。

```cpp
while (l < r) {
    int mid = (l + r) >> 1;
    if (a[mid] >= x) r = mid; else l = mid + 1;
}
return a[l];
```

| 维度 | 观察 |
| --- | --- |
| 语言 | C++，使用 `int`、数组、`return` |
| 缩进 | 4 空格 |
| 大括号 | `while` / `if` 后同行 `{`，与语句同行书写短分支 |
| 单行写法 | 简单的 `if...else` 写在同一行（`if (a[mid] >= x) r = mid; else l = mid + 1;`） |
| 运算符 | 位运算 `>>` 与比较运算符两侧有空格 |
| 变量命名 | 极短：`l`、`r`、`mid`、`a`、`x` |
| 数组下标 | 1-based（`l = 1, r = n`），第 0 位常留作哨兵 |
| 函数组织 | 模板直接给循环片段，不强制包成函数；例题才写 `valid()` / `main()` |
| 输入输出 | 例题中用 `scanf` / `printf` 与 `cin` / `cout` 混用 |

## 1.5 已观察到的书中风格（0x01 位运算）

来源：`[BOOK] p.15`（64 位乘法，已逐字符核对图像）；`[BOOK] p.5`（快速幂循环体）。

```cpp
long long mul(long long a, long long b, long long p) {
    long long ans = 0;
    for (; b; b >>= 1) {
        if (b & 1) ans = (ans + a) % p;
        a = a * 2 % p;
    }
    return ans;
}
```

| 维度 | 观察 |
| --- | --- |
| 循环写法 | `for (; b; b >>= 1)`——省略初值、以值本身作条件 |
| 位运算习惯 | `b & 1` 取最低位，`b >>= 1` 推进 |
| 溢出处理 | 关键乘法前 `(long long)` 强转，其余保持 int |
| 命名 | `a`、`b`、`p`、`ans`，无前缀 |
| 大数存储 | 统一 `long long` |

## 2. 本项目推荐规范

> 以下是在书中风格基础上做的**工程化约定** `[DERIVED]`，用于站点教学页与知识库代码块。

1. **保持竞赛风格**：不引入类、模板元编程、过度封装；函数短小直接。
2. **命名**：
   - 循环下标与端点保留 `l`、`r`、`mid`、`i`、`j`；
   - 数组用名词或单字母：`a`、`sum`、`fa`；
   - 判定函数统一 `bool check(...)` / `bool valid(...)`。
3. **下标**：与所在章节一致。本书多数章节使用 1-based，页面演示若用 0-based 必须在文案中注明。
4. **缩进**：4 空格；不使用 Tab。
5. **大括号**：多行块必须加括号；单行短分支可与书中一致写成一行，但同一页面内保持一致。
6. **注释**：
   - 段落注释说明「这一步在做什么」，而不是复述代码；
   - 数学符号用行内代码包裹。
7. **边界**：任何二分/DP 代码需在注释中标出初始区间含义（闭/半开）。
8. **复杂度**：每个算法块下方注明时间与空间复杂度。

## 3. 与站点现有页面的差异

站点 `public/lessons/binary-search.html` 的 lower_bound / upper_bound 演示采用：

- 左闭右开 `[l, r)`，初始 `[1, n+1)`；
- `while (l < r)`，`r = mid` / `l = mid + 1`。

这与本书 0x04 的**闭区间**写法不同但等价。后续页面若同时展示两套，必须显式对比说明，不能让学生误以为只有一种。
