## 6. 使用约定

1. 章节文档中出现结论性陈述时，必须给出 `[BOOK] p.XX` 或 `[DERIVED]`。
2. 同一页出现多个独立结论时，可复用同一页码，但要分别标注内容摘要。
3. 若页码来自推算而非直接阅读，标记 `(推算)`。
4. 任何 OCR 疑点先记入 §5，再决定是否采用。
