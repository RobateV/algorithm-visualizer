## 3. 核心知识点

### 3.1 补码

- **32 位无符号整数** `unsigned int`：直接把 32 位编码看作二进制数。
- **32 位有符号整数** `int`：最高位为符号位，0 非负、1 负；非负编码直接按二进制读，负数编码定义为「按位取反后的编码表示的数值再减 1」`[BOOK] p.2`。
- **性质**：
  - 每个数值都有**唯一**的补码表示；
  - 任意两个数的加减等价于 32 位补码下「最高位不进位」的二进制加减；
  - 无符号溢出相当于自动对 2³² 取模，这解释了有符号整数上溢出现负数的现象 `[BOOK] p.2`。
- **与反码（一补数）的关系**：反码把每一位取反表示负数；补码与反码在负数表示上的绝对值相差 1。补码解决了 0 的编码唯一性问题，能多表示一个数，电路实现简单高效 `[BOOK] p.2`。

### 3.2 十六进制与 `memset` 技巧

- 32 位补码用十六进制书写只需 8 个字符，每个字符对应 4 位；C++ 十六进制常数以 `0x` 开头，`0x` 只声明进制 `[BOOK] p.3`。
- `0x3F3F3F3F` 是满足「两倍不超过 `0x7FFFFFFF`」且「每 8 位相同」的最大整数 `[BOOK] p.3`。
- `memset(a, val, sizeof(a))` 把 `val` 填到**每个字节**上，因此只能构造「每 8 位都相同」的 int；`0x7F7F7F7F` 是 memset 能初始化出的最大值 `[BOOK] p.3`。
- 常用 `memset(a, 0x3f, sizeof(a))` 把数组置为 `0x3F3F3F3F` 以代替正无穷，避免加法溢出与繁琐判断 `[BOOK] p.3`。

### 3.3 移位运算

| 运算 | 规则 | 备注 |
| --- | --- | --- |
| 左移 `<<` | 低位补 0，高位越界舍弃 | `1 << n = 2^n` `[BOOK] p.3` |
| 算术右移 `>>` | 高位补**符号位**，低位越界舍弃 | 等价于除以 2 **向下取整**：`(-3) >> 1 = -2`，`3 >> 1 = 1` `[BOOK] p.4` |
| 逻辑右移 | 高位补 0 | C++ 未规定右移实现方式，由编译器决定；较新的 GCC 与 MSVC 均采用算术右移 `[BOOK] p.4` |

- **易混点**：`/ 2` 在 C++ 中是**向零取整**，`(-3) / 2 = -1`，与 `-2` 不同 `[BOOK] p.4`。书中建议读者自己编译验证 `[BOOK] p.4`。

### 3.4 快速幂

- **目标**：求 `a^b mod p`，`1 ≤ a, b, p ≤ 10^9` `[BOOK] p.4`。
- **核心**：每个正整数可唯一表示为若干指数不重复的 2 的幂之和；把 `b` 二进制拆分后逐项累乘 `[BOOK] p.4`。
- **遍历手段**：`b & 1` 取出最低位，`b >>= 1` 舍去最低位，二者结合遍历 `b` 的每一位 `[BOOK] p.4`。
- **复杂度**：`O(log b)` `[BOOK] p.4`。

### 3.5 64 位整数乘法

- **问题**：`a * b mod p`，`1 ≤ a, b, p ≤ 10^18`；C++ 最高只有 64 位整数，不存在可强转的 128 位类型 `[BOOK] p.5`。
- **方法一（倍增）**：把 `b` 二进制拆分，`a * 2^i = (a * 2^(i-1)) * 2`，递推求每项，结果始终不超过 `2 × 10^18`，仍在 `long long` 范围内；`O(log b)` `[BOOK] p.5`。
- **方法二（浮点 + 溢出）**：利用 `a * b mod p = a * b - ⌊a*b/p⌋ * p`；用 `long double` 算 `⌊a*b/p⌋`（18–19 位有效数字足够），再用 `long long` 保存 `a*b` 与 `c*p`——整数溢出相当于舍弃高位，正好得到所需的低位差 `[BOOK] p.6`。

### 3.6 二进制状态压缩

把长度为 m 的 bool 数组用一个 m 位二进制整数表示 `[BOOK] p.6`：

| 操作 | 运算 |
| --- | --- |
| 取出第 k 位 | `(n >> k) & 1` |
| 取出后 k 位 | `n & ((1 << k) - 1)` |
| 第 k 位取反 | `n ^ (1 << k)` |
| 第 k 位置 1 | `n \| (1 << k)` |
| 第 k 位赋 0 | `n & ~(1 << k)` |

- m 不大时用一个整数；较大时用整数数组或 `bitset`（见 0x71）`[BOOK] p.6`。

### 3.7 成对变换

- 对非负整数 n：n 为偶数时 `n xor 1 = n + 1`；n 为奇数时 `n xor 1 = n - 1` `[BOOK] p.9`。
- 因此「0 与 1」「2 与 3」「4 与 5」……构成成对变换 `[BOOK] p.9`。
- **应用**：邻接表中把一条无向边的正反两个方向分别存在第 `i` 与 `i+1` 位置（`i` 为偶数），则 `xor 1` 即可得到反向边的存储位置；详见 0x13 `[BOOK] p.9`。

### 3.8 lowbit

- **定义**：`lowbit(n)` 是非负整数 n 在二进制表示下「最低位的 1 及其后边所有 0」构成的数值。例如 `n = 10 = (1010)₂`，`lowbit(n) = 2 = (10)₂` `[BOOK] p.9`。
- **公式**：`lowbit(n) = n & (~n + 1) = n & -n` `[BOOK] p.10`。
- **推导**：设 n 的第 k 位是 1、第 0..k-1 位是 0。取反后第 k 位为 0、低位全 1；再加 1 进位，第 k 位回到 1、低位全 0，而第 k+1 位以上恰好与原数相反。故 `n & (~n+1)` 只有第 k 位为 1 `[BOOK] p.10`。
- **枚举所有 1 位**：不断令 `n -= lowbit(n)` 直到 0，时间复杂度与 1 的个数同级 `[BOOK] p.10`。
- **配合 Hash**：预处理 `H[2^k] = k`（k 较小时）；或用 `H[2^k mod 37] = k`，因为 `∀k ∈ [0,35]`，`2^k mod 37` 互不相等且恰好取遍 1..36 `[BOOK] p.10`。

### 3.9 运算符优先级

- 书中给出的从高到低顺序：**加减 → 移位 → 比较大小 → 位与 → 位或** `[BOOK] p.8`。
- **最需要注意**：大小比较的符号优先于「位与」「异或」「位或」；不确定时加括号 `[BOOK] p.7`。

## 4. 算法推导

### 4.1 快速幂为什么是 O(log b)

1. 把 `b` 写成 `c_{k-1}2^{k-1} + … + c_0 2^0`。
2. 则 `a^b = a^{c_{k-1}2^{k-1}} · … · a^{c_0 2^0}`。
3. 相邻两项满足 `a^{2^i} = (a^{2^{i-1}})^2`，可递推。
4. 逐位判断 `c_i` 是否为 1，是则把当前项乘入答案。
5. 位数为 `⌊log₂ b⌋ + 1`，故复杂度 `O(log b)` `[BOOK] p.4`。

### 4.2 64 位乘法为什么能用溢出

- 在方法二中，`a*b - c*p` 的真实值必在 `[0, p-1]` 内；
- 虽然 `a*b` 与 `c*p` 各自都可能溢出 64 位，但二者相减后的**低 64 位**恰好等于真实差值（模 2⁶⁴），所以用 `long long` 保存即可 `[BOOK] p.6`。

### 4.3 起床困难综合症的贪心

1. 位运算在二进制下不进位，因此**各位独立**：答案第 k 位只与初始攻击力第 k 位有关 `[BOOK] p.8`。
2. 从高位到低位逐位决定填 0 还是 1。
3. 填 1 当且仅当：① 在填高位加上 `1 << k` 不超过 m；② 该位填 1 的运算结果优于填 0 `[BOOK] p.8`。
4. 否则填 0 更优。

## 5. 代码实现

**快速幂** `[BOOK] p.4–5`（循环体在对照 p.15 图像；函数头 OCR 受损，标「待复核」）

```cpp
// 书中片段（函数头待复核）
int power(int a, int b, int p) {          // 计算 a^b mod p
    int ans = 1;                           // 待复核：初值
    for (; b; b >>= 1) {
        if (b & 1) ans = (long long)ans * a % p;
        a = (long long)a * a % p;          // 在核对：a = (long long)a * a % p;
    }
    return ans;
}
```

- **关键点**：乘法前必须把操作数转成 `long long`，因为两个 32 位整数相乘只用一个 32 位寄存器保存 `[BOOK] p.5`。

**64 位整数乘法（方法一）** `[BOOK] p.5`（**在逐字符核对页面图像**）

```cpp
long long mul(long long a, long long b, long long p) {
    long long ans = 0;
    for (; b; b >>= 1) {
        if (b & 1) ans = (ans + a) % p;
        a = a * 2 % p;
    }
    return ans;
}
```

**lowbit** `[BOOK] p.10`（公式，已在本地临时目录编译验证）

```cpp
#define lowbit(n) ((n) & -(n))
```

- **复杂度**：快速幂 `O(log b)`；64 位乘法 `O(log b)`；lowbit `O(1)` `[BOOK] p.4–5, p.10`。
- **常见实现错误**：`int` 溢出、`memset` 妄图初始化任意值、右移与除法混用、比较与位运算不加括号。

## 7. 易错点与注意事项

- **算术溢出**：两个 `int` 相乘结果仍是 32 位，必须 `(long long)` 转换 `[BOOK] p.5`。
- **右移与除法**：`>> 1` 向下取整，`/ 2` 向零取整，含负数时结果不同 `[BOOK] p.4`。
- **右移的实现方式**：C++ 未规定算术/逻辑右移，依赖编译器；本书默认算术右移 `[BOOK] p.4`。
- **`memset` 只能按字节填充**：只能得到「每 8 位相同」的值 `[BOOK] p.3`。
- **优先级陷阱**：`x & 1 == 0` 实际按 `x & (1 == 0)` 结合（比较优先于位与）`[BOOK] p.7–8`。
- **`lowbit(0) = 0`**：枚举 1 位时循环条件必须写 `n > 0`。
- **负数取模**：C++ 中 `%` 结果为负时与数学取模不同，需按题目要求处理（书中在快速幂处强调用 `long long` 后再取模）`[DERIVED]`。

## 9. 教学应用建议

> 教学设计建议，非原书内容 `[EXTENSION]`（设计层面）。

- **PPT 式讲解**：补码 → 移位 → 快速幂 → 状态压缩，先建立「位是独立的」这一直觉。
- **适合动画**：32 位补码的取反加一过程；`lowbit` 的「取反 + 1」位图变化；快速幂中 `a` 的逐次平方。
- **适合交互**：输入整数，实时显示二进制、十六进制、`lowbit`、`n xor 1`。
- **适合可视化的状态**：每一位的 0/1、`b` 的二进制指针、`ans` 的累乘过程。
- **代码同步行**：`if (b & 1)`、`b >>= 1`、`a = (long long)a * a % p`。
- **课堂问题**：为什么 `n & -n` 能取出最低位的 1？`(-3) >> 1` 与 `(-3) / 2` 为什么不同？
- **互动实验**：给 `memset(a, 0x3f, sizeof a)`，让学生预测每个 int 的值。
