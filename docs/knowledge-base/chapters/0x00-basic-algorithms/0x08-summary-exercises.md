## 3. 核心知识点

### 3.1 状态空间、遍历与映射（书的总结）

书中原文要点 `[BOOK] p.46`：

- 任何问题都有其涉及的范围，称为**状态空间**；求解就是在状态空间里的**遍历与映射**；
- **递推与递归**是遍历状态空间的两种基本形式；
- 后续算法是对「遍历顺序」「遍历过程中的决策方法」「状态之间映射方式」给出的指导；
- **枚举与模拟**：按问题直接表述对状态空间作**朴素遍历**；
- **搜索**：带有一定选择性、决策性的遍历；
- **贪心**：每步决策采取局部最优策略的遍历；
- **动态规划**：基于全局考量的分阶段、按维度、无重复遍历；
- **二分、倍增、排序**：对状态空间实施**划分、等价、代表、拼接**等手段，
  直接降低遍历时需要面对的时空规模 `[BOOK] p.46`。

## 6. 代表题精解（整理者）

### 6.1 糖果传递（BZOJ1045）

环上 `n` 人各持 `c[i]` 颗糖，相邻传递一颗，求最少次数 `[DERIVED]`：

- 平均 `avg = Σc/n`；令 `A[i] = c[i] − avg`，`S` 为前缀和；
- 断环于 `k`：代价 `Σ|S[i] − S[k]|`；
- 取 `S` 的中位数即最小，`O(n log n)`。

验证：`c = [1,0,5]` 时 `avg = 2`、`S = [−1,−3,0]`，中位数 `−1`，代价 `0+2+1 = 3`
（BFS 同样得到 3）。

### 6.2 Cow Acrobats（POJ3045）

`n` 头牛叠罗汉，牛 `i` 有重量 `w[i]`、力量 `s[i]`；风险 = 上方总重 − `s[i]`，最小化最大风险 `[DERIVED]`：

- 按 `w[i] + s[i]` **升序**排列最优（邻项交换可证）；
- 依次累加重量并更新最大风险，`O(n log n)`。

## 7. 易错点与注意事项

- **把总结当新知识**：本章是框架与练习，不要在此重复讲算法细节 `[DERIVED]`。
- **环形均分忘记断环**：线形公式不能直接用于环形 `[DERIVED]`。
- **Cow Acrobats 排序键写错**：是 `w+s` 升序，不是 `w` 或 `s` 单独排序 `[DERIVED]`。
- **二维转一维（To the Max）忘记枚举上下界** `[DERIVED]`。
- **离散化后坐标含义混乱**：Corral the Cows 等处需分清原坐标与离散化下标 `[DERIVED]`。
