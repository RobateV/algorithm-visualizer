## 3. 核心知识点

### 3.1 排序算法分类与复杂度下界

书中把常见排序分为三类 `[BOOK] p.32`：

| 类别 | 代表算法 | 时间复杂度 | 备注 |
| --- | --- | --- | --- |
| 一 | 选择、插入、冒泡 | `O(n²)` | 基于比较 |
| 二（堆/归并） | 堆排序、归并排序 | 最坏 `Θ(n log n)` | 达到比较排序的最坏情况下界 |
| 二（快速） | 快速排序 | 平均/期望 `O(n log n)`；最坏 `Θ(n²)` | 快，但最坏不满足下界 |
| 三 | 计数、基数、桶 | 与值域 `m` 有关 | 不直接比较大小 |

- **比较排序下界**：书中指出「基于比较的排序算法的时间复杂度下界为 `O(n log n)`」`[BOOK] p.32`。
  `[DERIVED]` 严格地说，**最坏情况下的下界**应写成 `Ω(n log n)`：任何基于比较的排序，
  最坏情况下至少需要 `Ω(n log n)` 次比较。`O(n log n)` 描述的是「可达的上界」，不能当上下界。
  - 堆排序、归并排序的最坏复杂度是 `Θ(n log n)`，因此**达到**下界；
  - 快速排序最坏 `Θ(n²)`，只有**平均/期望** `O(n log n)`——它不是一个「保证 `O(n log n)`」的算法。
- 第三类的时间复杂度「不仅与 `n` 有关，还与数值的大小范围 `m` 有关」`[BOOK] p.32`。
- `[DERIVED]` 三种口径必须分开：
  - **最坏**：堆排序、归并排序 `Θ(n log n)`；快速排序 `Θ(n²)`；
  - **平均**：快速排序 `Θ(n log n)`（对输入排列取平均）；
  - **期望**：随机化快排 `O(n log n)`（对随机数取期望，仍是概率意义）。

### 3.2 离散化

**定义** `[BOOK] p.32`：把无穷大集合中的若干元素映射到有限集合以便统计。
具体地，`n` 个可能重复的 `int` 整数（去重后 `m` 个）与 `1..m` 建立**保序映射**：
若 `a[i]` 小于（等于、大于）`a[j]`，则映射值也小于（等于、大于）。

**构造** `[BOOK] p.32–33`：

1. 把 `a[1..n]` 排序；
2. 去重得到 `b[1..m]`（`if (i==1 || a[i]!=a[i-1]) b[++m]=a[i]`）；
3. 查询 `x` 的映射值：`lower_bound(b+1, b+m+1, x) - b`。

**性质** `[DERIVED]`：

- 映射是**严格保序的双射**：不同值映射到不同下标，且大小关系完全保持；
- 重复元素映射到**同一个**下标（因此可以按值统计计数）；
- 预处理 `O(n log n)`，单次查询 `O(log m)`，空间 `O(n)`。

**Cinema 例题** `[BOOK] p.33`：`m` 部电影、`n` 个人，语言在 `int` 范围内但最多涉及 `2m+n` 种；
离散化后直接开数组统计每种语言的人数，再按「语音听懂优先、字幕其次」选电影。
复杂度 `O((n+m) log(n+m))`。

### 3.3 中位数与货仓选址

**货仓选址 CH0501** `[BOOK] p.33`：数轴上 `N` 家商店，选一点使距离之和最小。

- 排序后设货仓在 `X`，左侧 `P` 家、右侧 `Q` 家；
- 若 `P < Q`，右移 1 单位距离和减少 `Q − P`；若 `P > Q`，左移更优；`P = Q` 时为最优；
- 结论：`N` 为奇数时建在 `A[(N+1)/2]`；`N` 为偶数时建在 `[A[N/2], A[N/2+1]]` 之间任意位置 `[BOOK] p.33–34`。

### 3.4 七夕祭（BZOJ3032 / CH0502）

**题意** `[BOOK] p.34`：`N × M` 个摊位，`T` 个感兴趣；交换相邻摊位（同行/同列相邻，且首尾也算相邻），
使每行、每列感兴趣摊位数相同，求最多能满足几个要求及最少交换次数。

**关键观察** `[BOOK] p.34`：左右交换只改变列计数、上下交换只改变行计数，因此行列**独立**。

**均分纸牌模型** `[BOOK] p.34–35`：`M` 个人环/线排列，每人 `C[i]` 张，相邻传递一张，求最少次数。
设 `T` 为总数、平均 `T/M`，令 `A[i] = C[i] − T/M`，`S` 为 `A` 的前缀和，则

- **线形**最少次数 `= Σ_{i=1}^{M} |S[i]|`；
- 书中另给等价形式 `Σ |i·T/M − G[i]|`（`G` 为 `C` 的前缀和）`[BOOK] p.35`。

**环形 → 断点 → 中位数** `[BOOK] p.35–36`：

1. 环形时，最优解中**必存在一条不传递纸牌的相邻边**（可令某条边的净流量为 0）；
2. 枚举断点 `k`，断成线后每个前缀和变为 `S[i] − S[k]`（循环意义下），代价 `Σ |S[i] − S[k]|`；
3. 把 `S[1..M]` 看作数轴上的点、`S[k]` 看作货仓 → 取 `S` 的**中位数**即最优，无需枚举 `k`；
4. 总复杂度 `O(N log N + M log M)` `[BOOK] p.36`。

**最多能满足几个要求** `[DERIVED]`：分别判断 `T % N == 0`（行）与 `T % M == 0`（列），
两者都满足输出 `both`，只有一个满足输出对应方向，都不满足 `impossible`。

### 3.5 Running Median（POJ3784）

**题意** `[BOOK] p.36`：依次读入整数，每当已读入个数为奇数时输出当前中位数。

**对顶堆** `[BOOK] p.36–37`。书中按「较小的前 `M/2` 个 / 较大的后一半」描述；
`[DERIVED]` 更精确的不变量（本章统一采用）：

设当前元素个数为 `M`：

1. **大小**：大根堆存**较小的 `⌊M/2⌋`** 个元素，小根堆存**较大的 `⌈M/2⌉`** 个元素；
2. **跨堆有序**：大根堆中任意元素 `≤` 小根堆中任意元素（等价于 `big.top() ≤ small.top()`）；
3. **中位数**：`M` 为奇数时，中位数恒为**小根堆堆顶**（它是第 `(M+1)/2` 小）；
   `M` 为偶数时，中位数是 `big.top()` 与 `small.top()` 之间的任意值（常取平均）。

**插入规则** `[BOOK] p.37`：书中描述为「`X` 比当前中位数小则插入大根堆，否则插入小根堆，再调整」。
`[DERIVED]` 该规则只是**减少调整次数**的启发式；下面 §5.3 的实现改为按两堆大小与堆顶决定方向，
可证明每次插入后三条不变量都成立。

### 3.6 第 k 大数（快速选择）

**题意** `[BOOK] p.37`：求 `n` 个数中第 `k` 大，直接排序是 `O(n log n)`，本章给出平均 `O(n)` 的做法。

**做法**（类似快速排序）`[BOOK] p.37`：

1. 随机选基准，把**比基准大的**换到左半段，其余（含基准）放右半段；
2. 统计左半段元素个数 `cnt`；
3. 若 `k ≤ cnt`，在左半段找第 `k` 大；否则在右半段找第 `k − cnt` 大；
4. 只递归**一侧**，平均复杂度 `n + n/2 + n/4 + … = O(n)`。

**⚠ 书中的二路划分有退化风险** `[DERIVED]`：上述划分把「等于基准」的元素全部留在右半段。
当**所有元素相等**且求第 `n` 大时，每次划分左半段为空、右半段大小为 `n−1`，
递归链长度为 `n`，总代价 `n + (n−1) + … + 1 = Θ(n²)`。

**修正：三路划分**（`> pivot` / `== pivot` / `< pivot`）：

- 设大于、等于、小于 pivot 的个数分别为 `gt`、`eq`、`lt`；
- 若 `k ≤ gt` → 左段找第 `k` 大；
- 若 `gt < k ≤ gt + eq` → 第 `k` 大就是 `pivot`，直接返回；
- 否则 → 右段找第 `k − gt − eq` 大。

全部元素相等时 `gt = lt = 0`、`eq = n`，一次划分即返回，`Θ(n)`。
三路划分也是 C++ `std::nth_element` 常用策略的简化版 `[EXTENSION]`。

### 3.7 逆序对

**定义** `[BOOK] p.37`：`i < j` 且 `a[i] > a[j]`，称 `(a[i], a[j])` 为一对逆序对。

**归并排序统计** `[BOOK] p.37–38`：

- 左右两半各自内部的逆序对递归统计；
- 合并时，若 `a[j]` 被取出（`a[j] < a[i]`），则 `a[i..mid]` 全部大于 `a[j]`，
  与 `a[j]` 构成 `mid − i + 1` 个跨区间逆序对；
- 代码中用 `a[i] <= a[j]` 优先取左，保证**相等元素不被计入** `[BOOK] p.38`。

**Ultra-QuickSort（POJ2299）** `[BOOK] p.38`：只允许相邻交换时，最少交换次数 = 逆序对数。

### 3.8 奇数码问题（CH0503）

**题意** `[BOOK] p.38`：`n` 为奇数，`n×n` 网格中放 `1..n²−1` 与一个空格；
判断两个局面能否互相到达（`3 ≤ n ≤ 500`）。扩展题：POJ2893 `M × N Puzzle`。

> **原书到本题的题面为止，没有给出判定方法与证明** `[BOOK] p.38`。
> 下面的奇偶性判定与证明是整理者补充，标 `[DERIVED]`。

**判定**（`n` 为奇数）`[DERIVED]`：把网格按行优先去掉空格后得到 `1..n²−1` 的排列，
两局面**可达当且仅当逆序对个数的奇偶性相同**。

- **必要性**（本报告已证）：空格每次移动都不改变逆序对奇偶性，见 §4.9；
- **充分性**：这是 15-puzzle 的经典结论（奇偶性相同即可达），但本报告**没有给出完整构造证明**，
  只给出思路，标「待严格证明」，见 §4.9。

**规模提醒** `[DERIVED]`：`n ≤ 500` 时元素数 `n²−1` 可达 `2.5×10^5`；
用双重循环统计逆序对是 `O(n⁴)`，`n = 500` 时约 `6×10^10` 次比较，必然超时。
应把去掉空格后的序列摊平成一维，用**归并排序或树状数组**在 `O(n² log n)` 内统计奇偶性。

## 4. 算法推导

### 4.1 比较排序下界（书中结论）

书中直接给出「基于比较的排序算法时间复杂度下界为 `O(n log n)`」`[BOOK] p.32`，未展开证明。
`[DERIVED]` 补充思路：`n` 个元素有 `n!` 种排列，每次比较只能区分 2 种结果，
决策树高度 `h` 满足 `2^h ≥ n!`，由 Stirling 公式 `h = Ω(n log n)`。

### 4.2 离散化为什么保序且可统计

- 排序后 `b` 递增且无重复，`lower_bound` 返回第一个 `≥ x` 的位置，
  对 `x ∈ b` 而言正好是其下标，且下标随值单调 → **保序** `[DERIVED]`；
- 相同值得到相同下标 → 可直接用下标作为计数数组的键 `[DERIVED]`；
- 若 `x` 不在 `b` 中，`lower_bound` 返回插入位置，调用方需自行决定语义 `[DERIVED]`。

### 4.3 货仓选址的最小值（两种解释）

**交换论证** `[BOOK] p.33`：把货仓从 `X` 向右移动 `δ`，左侧 `P` 家距离各增 `δ`、
右侧 `Q` 家各减 `δ`，总变化 `(P − Q)δ`。`P < Q` 时变化为负 → 右移更优；
`P > Q` 时左移更优；只有 `P = Q` 时两侧平衡 `[BOOK] p.33`。

**函数视角** `[DERIVED]`：`f(X) = Σ|A[i] − X|` 是凸函数，分段线性，斜率在穿过每个 `A[i]` 时增加 2；
最小值取在斜率变号处，即中位数（偶数时为中间区间）。

### 4.4 均分纸牌公式的证明

线形、总数为 `T`、平均 `avg = T/M`，`A[i] = C[i] − avg`，`S[i] = Σ_{j≤i} A[j]` `[DERIVED]`：

- **下界**：边 `(i, i+1)` 两侧的前缀净差为 `S[i]`，必须通过这条边净传递 `|S[i]|` 张，
  故总次数 `≥ Σ|S[i]|`；
- **可达**：从左到右，第 `i` 个人与第 `i+1` 个人之间恰好传递 `S[i]` 张（正负表示方向），
  每一步都只改变相邻两人，最终全部归零，总次数恰为 `Σ|S[i]|`。

### 4.5 环形均分 → 货仓选址（完整证明）

**引理：最优解中必有一条边净流量为 0** `[DERIVED]`。

设环上每条边的净流量为 `f[i]`（方向统一），守恒条件 `f[i] − f[i−1] = −A[i]`。
所有可行解只差一个常数：`f[i] = f0[i] + c`，代价 `F(c) = Σ|f0[i] + c|`。

**⚠ 修正：最小值由中位数决定，不是 `c = −min f0`**

反例 `C = [3, 3, 0]`（平均 2，`A = [1, 1, −2]`），取参考解 `f0[i] = −S[i] = [−1, −2, 0]`：

| 偏移 | 流量 | 代价 |
| --- | --- | --- |
| `c = 2 = −min f0` | `[1, 0, 2]` | **3** |
| `c = 1 = −median f0` | `[0, −1, 1]` | **2**（BFS 验证最优为 2） |

所以「取最小值抵消」并不最优。

**中位数最优的证明**（严格版）：设 `x_i = −f0[i]`，`F(t) = Σ|x_i − t|`。

**配对不等式**：把 `x` 升序排列为 `y_1 ≤ y_2 ≤ … ≤ y_m`。对任意 `t`，配对首尾：

```
|y_i − t| + |y_{m+1−i} − t| ≥ |y_{m+1−i} − y_i| = y_{m+1−i} − y_i
```

（三角不等式）。对 `i = 1..⌊m/2⌋` 求和得

```
F(t) ≥ Σ_{i=1}^{⌊m/2⌋} (y_{m+1−i} − y_i)
```

**取等条件**：当 `t` 落在中间区间时每一项都取等——
`m` 为奇数时 `t = y_{(m+1)/2}`；`m` 为偶数时 `t ∈ [y_{m/2}, y_{m/2+1}]`。
故中位数（区间）最小，且最小值正是上式右端。

**分段斜率视角**（辅助理解）：`F` 是分段线性的，在相邻数据点之间斜率为
`(#小于 t) − (#大于 t)`；每穿过一个数据点斜率增加 2，斜率在中间统计量处由负变正。
注意 `(p−q)δ` 只在**不跨越数据点**的区间内成立，不能直接用于任意 `δ`——
完整证明是上面的配对不等式。

**零流量边**：排序后取中位数，它必等于某个 `x_i`，即存在 `i` 使 `f0[i] + c = 0`。
因此存在一个最优解，其某条边的净流量为 0，断环成链的前提成立。

> 常见的错误是「取 `c` 抵消最小值」；正确做法是「取 `c` 使偏移后的中位数为 0」，
> 等价于在 `S[1..M]` 上取中位数，与书中的断点公式一致 `[BOOK] p.36`。

**断点代价** `[BOOK] p.35–36`：在第 `k` 个人之后断开，前缀和变为 `S[i] − S[k]`（循环取模），
代价 `Σ_{i} |S[i] − S[k]|`。

**取中位数** `[BOOK] p.36`：把 `{S[1..M]}` 视作数轴上的点，`S[k]` 视作货仓位置，
由 §4.3 知取中位数最小；`S[M] = 0`（因为 `ΣA = 0`），所以中位数在 `S[1..M]` 中取。

**总体** `[BOOK] p.36`：行、列各做一次环形均分，答案相加；有解性分别由 `T % N`、`T % M` 判断。

### 4.6 对顶堆的不变量

**不变量与维护** `[DERIVED]`：

- 大根堆恰含最小的 `⌊M/2⌋` 个元素，小根堆恰含最大的 `⌈M/2⌉` 个元素；
- `big.top() ≤ small.top()`（跨堆有序）；
- `M` 为奇数时中位数 = `small.top()`。

**插入（两次比较、一次移动）**：

设插入前 `big.size() = b`、`small.size() = s`，且 `s ∈ {b, b+1}`：

- 若 `b == s`（`M` 为偶数）：插入后 `M` 为奇数，应让小根堆多一个。
  - `x ≥ big.top()`（或 `big` 为空）→ `small.push(x)`；
  - 否则 `small.push(big.top()); big.pop(); big.push(x);`
- 若 `s == b + 1`（`M` 为奇数）：插入后两堆相等。
  - `x ≤ small.top()` → `big.push(x)`；
  - 否则 `big.push(small.top()); small.pop(); small.push(x);`

**为什么保持跨堆有序**：每次把某个堆的堆顶搬到另一个堆时，被搬元素恰好是该方向上的边界值
（大根堆堆顶是较小半的最大值、小根堆堆顶是较大半的最小值），因此搬动后仍满足 `big.top() ≤ small.top()`。
两种分支都只做常数次堆操作，单次插入 `O(log n)` `[DERIVED]`。

> 书中的「与中位数比较后插入」只是上述过程的一种直觉版本；
> 仅靠「插入后把大小差调回 1」**不能**保证跨堆有序，这一点在 §5.3 的实现中已修正。

### 4.7 快速选择为什么只递归一侧

三路划分后区间被分成 `>`、`=`、`<` 三段，段长 `gt`、`eq`、`lt` 都已知 `[DERIVED]`：

- `k ≤ gt`：第 `k` 大在「大于 pivot」段；
- `gt < k ≤ gt + eq`：第 `k` 大就是 `pivot`，**无需继续递归**；
- `k > gt + eq`：在「小于 pivot」段中找第 `k − gt − eq` 大。

**为什么全相等时三路是线性的**：一次划分把全部元素放入「等于」段，直接返回，`Θ(n)`。

**复杂度口径** `[DERIVED]`：

| 场景 | 复杂度 |
| --- | --- |
| 随机基准的**期望** | `O(n)`（递推 `T(n) = T(αn) + O(n)` 的加权平均） |
| **最坏** | `Θ(n²)`（每次划分极不均衡）；随机化只降低其概率，不改变最坏界 |
| 全相等（三路） | `Θ(n)`（一次划分即命中） |

> 平均情况：若基准把区间划分为 `α : 1−α`，递推 `T(n) = T(αn) + O(n)`；
> 对均匀随机基准取期望得 `O(n)`；而不能据此说「最坏也是 `O(n)`」。

### 4.8 归并统计逆序对的正确性

- **不重**：每对逆序对 `(i, j)` 在递归中只会在「`i` 在左半、`j` 在右半」的那一层被统计一次 `[DERIVED]`；
- **不漏**：同一半内部的由递归保证，跨半的由合并统计；
- **计数公式**：合并时若 `a[j] < a[i]`，则 `a[i..mid]` 均 `≥ a[i] > a[j]`，
  共 `mid − i + 1` 对；用 `a[i] <= a[j]` 优先左半，保证相等元素不计入 `[BOOK] p.38`；
- **溢出**：逆序对最多 `n(n−1)/2`，`n = 5×10^5` 时约 `1.25×10^11`，必须用 `long long` `[DERIVED]`。

### 4.9 奇数码的奇偶性判定（`n` 为奇数）

**不变量：逆序对奇偶性不变** `[DERIVED]`。

1. 空格**左右**移动：排列不变，逆序对数不变；
2. 空格**上下**移动：被移动的数字在排列中向前/向后移动 `n − 1` 个位置，
   等价于它与跨过的 `n − 1` 个非空数字依次做 **`n − 1` 次相邻交换**。
   而**一次相邻交换恰好使逆序对数改变 ±1**（只改变这两个数字之间的一对关系），
   即奇偶性翻转一次；翻转偶数次则奇偶性不变。
   由于 `n` 为奇数 ⇒ `n − 1` 为偶数 ⇒ **逆序对奇偶性不变**。

**充分性：本报告未给出严格证明** `[DERIVED]`（书中亦未证）。

- 这是 15-puzzle / 奇数码的经典结论：固定空格位置后，可达状态恰为某一奇偶类；
  标准证明依赖「空格可生成 3-循环」「3-循环生成交错群」等群论结果。
- 本报告**不把「三循环可以生成全部偶置换」当作已完成的证明**：它只是证明路线提纲，
  还需要说明「如何在不改变空格位置的前提下构造所需 3-循环」。
- 因此充分性标为**待严格证明**，仅作为已知经典结论使用。
- 3×3 的 BFS 只验证了 `n = 3`（§11.4），**不能替代任意奇数 `n` 的一般证明**。

> 注：`n` 为偶数时（POJ2893 的 `M×N`），还需把空格所在行计入奇偶性，属扩展内容 `[EXTENSION]`。

void merge(int l, int mid, int r) {
    int i = l, j = mid + 1;
    for (int k = l; k <= r; k++)
        if (j > r || i <= mid && a[i] <= a[j]) b[k] = a[i++];
        else b[k] = a[j++], cnt += mid - i + 1;
    for (int k = l; k <= r; k++) a[k] = b[k];

### 5.3 对顶堆（Running Median）`[DERIVED]`（书中只给规则，未给代码）

```cpp
priority_queue<int> big;                              // 较小的一半（大根堆）
priority_queue<int, vector<int>, greater<int>> small; // 较大的一半（小根堆）

// 不变量：big.size() == small.size() 或 small.size() == big.size()+1；
//         且 big.top() <= small.top()
void insert(int x) {
    if (big.size() == small.size()) {                 // 偶数个，插入后 small 应多一个
        if (big.empty() || x >= big.top()) {
            small.push(x);
        } else {
            small.push(big.top()); big.pop(); big.push(x);
        }
    } else {                                          // small 比 big 多一个
        if (x <= small.top()) {
            big.push(x);
        } else {
            big.push(small.top()); small.pop(); small.push(x);
        }
    }
}

int median() {                       // 仅当当前长度为奇数时调用
    return small.top();              // 第 (M+1)/2 小
}
double medianEven() {                // 长度为偶数时的常用约定
    // 必须先各自转 long long 再相加：int 相加会溢出（INT_MAX + INT_MAX 是 UB）
    return (static_cast<long long>(big.top()) + static_cast<long long>(small.top())) / 2.0;
}
```

### 5.4 快速选择 `[DERIVED]`

```cpp
// 三路划分：[l, lt) > pivot, [lt, gt] == pivot, (gt, r] < pivot
int kth(vector<int>& a, int l, int r, int k) {   // 第 k 大，1-based
    if (l == r) return a[l];
    int p = l + rand() % (r - l + 1);
    int pivot = a[p];
    int lt = l, i = l, gt = r;
    while (i <= gt) {
        if (a[i] > pivot) swap(a[lt++], a[i++]);
        else if (a[i] < pivot) swap(a[i], a[gt--]);
        else i++;
    }
    int gtCnt = lt - l;              // 严格大于 pivot 的个数
    int eqCnt = gt - lt + 1;         // 等于 pivot 的个数
    if (k <= gtCnt) return kth(a, l, lt - 1, k);
    if (k <= gtCnt + eqCnt) return pivot;        // 落入等值段，直接返回
    return kth(a, gt + 1, r, k - gtCnt - eqCnt);
}
```

> 与 §5.4 旧版（严格二路）相比，三路版本在大量重复元素时不会退化；
> 全部相等且 `k = n` 时旧版实测比较次数约 `n²/2`，三路版为 `n`（见 §11.5）。

## 7. 易错点与注意事项

- **离散化后忘记查询用 `lower_bound`**：`query` 必须二分，不能假设下标就是值 `[DERIVED]`。
- **离散化改变了下标含义**：原数组与映射数组不要混用 `[DERIVED]`。
- **环形均分直接套线形公式**：必须先断环并取中位数 `[BOOK] p.35–36`。
- **环形均分用「抵消最小值」找零流量边**：错误；最优偏移由**中位数**决定（§4.5 反例）。
- **对顶堆只调整大小不检查跨堆有序**：必须保证 `big.top() ≤ small.top()`（§4.6）。
- **行列未分别判断整除**：`T % N`、`T % M` 决定最多能满足几个要求 `[DERIVED]`。
- **逆序对计数用 `int`**：`n = 5×10^5` 时答案超 `int`，必须 `long long` `[DERIVED]`。
- **相等元素被计入逆序对**：合并时必须 `a[i] <= a[j]` 优先左半 `[BOOK] p.38`。
- **快速选择递归了两侧**：只递归包含第 `k` 大的一侧，否则退化为快排 `[DERIVED]`。
- **快速选择用二路划分处理大量重复元素**：全部相等且 `k = n` 时退化为 `Θ(n²)`，应用三路划分 `[DERIVED]`。
- **把 `O(n log n)` 称为比较排序下界**：下界应写 `Ω(n log n)` `[DERIVED]`。
- **把奇数码的奇偶性判定当成已证充分性**：本报告只证了必要性，充分性待严格证明 `[DERIVED]`。
- **对顶堆用 `int` 存不下**：元素值大时用 `long long` 堆 `[DERIVED]`。
- **奇数码忘记 `n` 为奇数的前提**：`n` 为偶数时判定还需空格行号 `[DERIVED]`。
- **`n` 为偶数用错公式**：POJ2893 属扩展，不在本章原书范围 `[EXTENSION]`。

结果：全部保持，`0` 次违反。

**快速选择**：

- 6 类数组（全相等、大量重复、严格递增、严格递减、随机互异、随机重复）逐 `k` 校验，全部与 `sort` 一致；
- 退化对照（全相等 `n = 1500`、`k = n`）：

| 版本 | 比较次数 |
| --- | --- |
| 严格二路（旧版） | 1,124,250（≈ `n²/2`） |
| 三路（新版） | 1,500（`n`） |

> 该对照同时复现了「二路划分在大量重复元素上退化为 `Θ(n²)`」的现象。

### 11.6 第三轮补充测试

**`medianEven()` 的有符号溢出**（UBSan / trap 模式，本机 MinGW 无 libubsan，使用
`-fsanitize=undefined -fsanitize-undefined-trap-on-error`）：

| 版本 | 输入 | 结果 |
| --- | --- | --- |
| `(big.top() + small.top()) / 2.0`（int 相加） | `INT_MAX, INT_MAX` | ❌ 触发非法指令（trap），确认是 UB |
| `((long long)big.top() + (long long)small.top()) / 2.0` | `INT_MAX, INT_MAX` | ✅ 输出 `4294967294`，正常退出 |
