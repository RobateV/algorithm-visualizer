## 3. 核心知识点

### 3.1 排序算法分类与复杂度下界

书中把常见排序分为三类 `[BOOK] p.32`：

| 类别 | 代表算法 | 时间复杂度 | 备注 |
| --- | --- | --- | --- |
| 一 | 选择、插入、冒泡 | `O(n²)` | 基于比较 |
| 二 | 堆、归并、快速 | `O(n log n)` | 基于比较，已是比较排序的下界 |
| 三 | 计数、基数、桶 | 与值域 `m` 有关 | 不直接比较大小 |

- **比较排序下界**：书中直接指出「基于比较的排序算法的时间复杂度下界为 `O(n log n)`」`[BOOK] p.32`。
- 第三类的时间复杂度「不仅与 `n` 有关，还与数值的大小范围 `m` 有关」`[BOOK] p.32`。
- `[DERIVED]` 严格区分三种口径：
  - **最坏**：堆/归并 `O(n log n)`；快速排序最坏 `O(n²)`；
  - **平均**：快速排序 `O(n log n)`；
  - **期望**：随机化快排 `O(n log n)`（对输入分布取期望）。

### 3.2 离散化

**定义** `[BOOK] p.32`：把无穷大集合中的若干元素映射到有限集合以便统计。
具体地，`n` 个可能重复的 `int` 整数（去重后 `m` 个）与 `1..m` 建立**保序映射**：
若 `a[i]` 小于（等于、大于）`a[j]`，则映射值也小于（等于、大于）。

**构造** `[BOOK] p.32–33`：

1. 把 `a[1..n]` 排序；
2. 去重得到 `b[1..m]`（`if (i==1 || a[i]!=a[i-1]) b[++m]=a[i]`）；
3. 查询 `x` 的映射值：`lower_bound(b+1, b+m+1, x) - b`。

**性质** `[DERIVED]`：

- 映射是**严格保序的双射**：不同值映射到不同下标，且大小关系完全保持；
- 重复元素映射到**同一个**下标（因此可以按值统计计数）；
- 预处理 `O(n log n)`，单次查询 `O(log m)`，空间 `O(n)`。

**Cinema 例题** `[BOOK] p.33`：`m` 部电影、`n` 个人，语言在 `int` 范围内但最多涉及 `2m+n` 种；
离散化后直接开数组统计每种语言的人数，再按「语音听懂优先、字幕其次」选电影。
复杂度 `O((n+m) log(n+m))`。

### 3.3 中位数与货仓选址

**货仓选址 CH0501** `[BOOK] p.33`：数轴上 `N` 家商店，选一点使距离之和最小。

- 排序后设货仓在 `X`，左侧 `P` 家、右侧 `Q` 家；
- 若 `P < Q`，右移 1 单位距离和减少 `Q − P`；若 `P > Q`，左移更优；`P = Q` 时为最优；
- 结论：`N` 为奇数时建在 `A[(N+1)/2]`；`N` 为偶数时建在 `[A[N/2], A[N/2+1]]` 之间任意位置 `[BOOK] p.33–34`。

### 3.4 七夕祭（BZOJ3032 / CH0502）

**题意** `[BOOK] p.34`：`N × M` 个摊位，`T` 个感兴趣；交换相邻摊位（同行/同列相邻，且首尾也算相邻），
使每行、每列感兴趣摊位数相同，求最多能满足几个要求及最少交换次数。

**关键观察** `[BOOK] p.34`：左右交换只改变列计数、上下交换只改变行计数，因此行列**独立**。

**均分纸牌模型** `[BOOK] p.34–35`：`M` 个人环/线排列，每人 `C[i]` 张，相邻传递一张，求最少次数。
设 `T` 为总数、平均 `T/M`，令 `A[i] = C[i] − T/M`，`S` 为 `A` 的前缀和，则

- **线形**最少次数 `= Σ_{i=1}^{M} |S[i]|`；
- 书中另给等价形式 `Σ |i·T/M − G[i]|`（`G` 为 `C` 的前缀和）`[BOOK] p.35`。

**环形 → 断点 → 中位数** `[BOOK] p.35–36`：

1. 环形时，最优解中**必存在一条不传递纸牌的相邻边**（可令某条边的净流量为 0）；
2. 枚举断点 `k`，断成线后每个前缀和变为 `S[i] − S[k]`（循环意义下），代价 `Σ |S[i] − S[k]|`；
3. 把 `S[1..M]` 看作数轴上的点、`S[k]` 看作货仓 → 取 `S` 的**中位数**即最优，无需枚举 `k`；
4. 总复杂度 `O(N log N + M log M)` `[BOOK] p.36`。

**最多能满足几个要求** `[DERIVED]`：分别判断 `T % N == 0`（行）与 `T % M == 0`（列），
两者都满足输出 `both`，只有一个满足输出对应方向，都不满足 `impossible`。

### 3.5 Running Median（POJ3784）

**题意** `[BOOK] p.36`：依次读入整数，每当已读入个数为奇数时输出当前中位数。

**对顶堆** `[BOOK] p.36–37`：

- 大根堆存排序后**前 `M/2` 小**的元素（较小的一半）；
- 小根堆存**后一半**（`M/2+1 ~ M`）；
- 任一时刻某堆元素过多，就弹出堆顶插入另一堆；
- 中位数 = **小根堆堆顶**。

**插入规则** `[BOOK] p.37`：`X` 比当前中位数小则插入大根堆，否则插入小根堆，再检查并维护上述性质。

### 3.6 第 k 大数（快速选择）

**题意** `[BOOK] p.37`：求 `n` 个数中第 `k` 大，直接排序是 `O(n log n)`，本章给出平均 `O(n)` 的做法。

**做法**（类似快速排序）`[BOOK] p.37`：

1. 随机选基准，把**比基准大的**换到左半段，其余（含基准）放右半段；
2. 统计左半段元素个数 `cnt`；
3. 若 `k ≤ cnt`，在左半段找第 `k` 大；否则在右半段找第 `k − cnt` 大；
4. 只递归**一侧**，平均复杂度 `n + n/2 + n/4 + … = O(n)`。

### 3.7 逆序对

**定义** `[BOOK] p.37`：`i < j` 且 `a[i] > a[j]`，称 `(a[i], a[j])` 为一对逆序对。

**归并排序统计** `[BOOK] p.37–38`：

- 左右两半各自内部的逆序对递归统计；
- 合并时，若 `a[j]` 被取出（`a[j] < a[i]`），则 `a[i..mid]` 全部大于 `a[j]`，
  与 `a[j]` 构成 `mid − i + 1` 个跨区间逆序对；
- 代码中用 `a[i] <= a[j]` 优先取左，保证**相等元素不被计入** `[BOOK] p.38`。

**Ultra-QuickSort（POJ2299）** `[BOOK] p.38`：只允许相邻交换时，最少交换次数 = 逆序对数。

### 3.8 奇数码问题（CH0503）

**题意** `[BOOK] p.38`：`n` 为奇数，`n×n` 网格中放 `1..n²−1` 与一个空格；
判断两个局面能否互相到达（`3 ≤ n ≤ 500`）。扩展题：POJ2893 `M × N Puzzle`。

> **原书到本题的题面为止，没有给出判定方法与证明** `[BOOK] p.38`。
> 下面的奇偶性判定与证明是整理者补充，标 `[DERIVED]`。

**判定**（`n` 为奇数）`[DERIVED]`：把网格按行优先去掉空格后得到 `1..n²−1` 的排列，
两局面**可达当且仅当逆序对个数的奇偶性相同**。

证明见 §4.9。

## 4. 算法推导

### 4.1 比较排序下界（书中结论）

书中直接给出「基于比较的排序算法时间复杂度下界为 `O(n log n)`」`[BOOK] p.32`，未展开证明。
`[DERIVED]` 补充思路：`n` 个元素有 `n!` 种排列，每次比较只能区分 2 种结果，
决策树高度 `h` 满足 `2^h ≥ n!`，由 Stirling 公式 `h = Ω(n log n)`。

### 4.2 离散化为什么保序且可统计

- 排序后 `b` 递增且无重复，`lower_bound` 返回第一个 `≥ x` 的位置，
  对 `x ∈ b` 而言正好是其下标，且下标随值单调 → **保序** `[DERIVED]`；
- 相同值得到相同下标 → 可直接用下标作为计数数组的键 `[DERIVED]`；
- 若 `x` 不在 `b` 中，`lower_bound` 返回插入位置，调用方需自行决定语义 `[DERIVED]`。

### 4.3 货仓选址的最小值（两种解释）

**交换论证** `[BOOK] p.33`：把货仓从 `X` 向右移动 `δ`，左侧 `P` 家距离各增 `δ`、
右侧 `Q` 家各减 `δ`，总变化 `(P − Q)δ`。`P < Q` 时变化为负 → 右移更优；
`P > Q` 时左移更优；只有 `P = Q` 时两侧平衡 `[BOOK] p.33`。

**函数视角** `[DERIVED]`：`f(X) = Σ|A[i] − X|` 是凸函数，分段线性，斜率在穿过每个 `A[i]` 时增加 2；
最小值取在斜率变号处，即中位数（偶数时为中间区间）。

### 4.4 均分纸牌公式的证明

线形、总数为 `T`、平均 `avg = T/M`，`A[i] = C[i] − avg`，`S[i] = Σ_{j≤i} A[j]` `[DERIVED]`：

- **下界**：边 `(i, i+1)` 两侧的前缀净差为 `S[i]`，必须通过这条边净传递 `|S[i]|` 张，
  故总次数 `≥ Σ|S[i]|`；
- **可达**：从左到右，第 `i` 个人与第 `i+1` 个人之间恰好传递 `S[i]` 张（正负表示方向），
  每一步都只改变相邻两人，最终全部归零，总次数恰为 `Σ|S[i]|`。

### 4.5 环形均分 → 货仓选址（完整证明）

**引理：最优解中必有一条边净流量为 0** `[DERIVED]`。

设环上每条边的净流量为 `f[i]`（正方向统一），守恒条件为 `f[i] − f[i−1] = −A[i]`。
所有可行解只差一个常数：`f[i] = f0[i] + c`。代价 `Σ|f[i]|` 关于 `c` 是凸函数，
在 `c = −min f0` 处取到最小值且此时某条边为 0。故存在最优解不断开某条边。

**断点代价** `[BOOK] p.35–36`：在第 `k` 个人之后断开，前缀和变为 `S[i] − S[k]`（循环取模），
代价 `Σ_{i} |S[i] − S[k]|`。

**取中位数** `[BOOK] p.36`：把 `{S[1..M]}` 视作数轴上的点，`S[k]` 视作货仓位置，
由 §4.3 知取中位数最小；`S[M] = 0`（因为 `ΣA = 0`），所以中位数在 `S[1..M]` 中取。

**总体** `[BOOK] p.36`：行、列各做一次环形均分，答案相加；有解性分别由 `T % N`、`T % M` 判断。

### 4.6 对顶堆的不变量

不变量 `[DERIVED]`：设当前元素数 `M`，则

- 大根堆恰含最小的 `⌊M/2⌋` 个元素；
- 小根堆恰含最大的 `⌈M/2⌉` 个元素；
- 因此小根堆堆顶是第 `⌈M/2⌉+`? 准确地说：`M` 为奇数时中位数是第 `(M+1)/2` 小，正好是小根堆堆顶。

维护：插入后若两堆大小差超过 1，把较大堆的堆顶移到另一堆；每次调整 `O(log n)`。
`[DERIVED]` 插入位置按「与当前中位数比较」决定，是为了**减少调整次数**，不是正确性的必要条件——
即使随意插入再调整也能得到正确中位数。

### 4.7 快速选择为什么只递归一侧

一次划分后，左半段全部 **大于** 基准、右半段全部 **≤** 基准，且左半段大小 `cnt` 已知 `[DERIVED]`：

- 若 `k ≤ cnt`，第 `k` 大一定在左半段，右半段整段可以丢弃；
- 若 `k > cnt`，第 `k` 大在右半段，且是右半段的第 `k − cnt` 大。

每层只处理一个子问题，平均规模减半，故 `T(n) = T(n/2) + O(n) = O(n)`；
最坏（每次划分极不均衡）退化为 `O(n²)`，随机选基准可让最坏情况的概率极低 `[DERIVED]`。

### 4.8 归并统计逆序对的正确性

- **不重**：每对逆序对 `(i, j)` 在递归中只会在「`i` 在左半、`j` 在右半」的那一层被统计一次 `[DERIVED]`；
- **不漏**：同一半内部的由递归保证，跨半的由合并统计；
- **计数公式**：合并时若 `a[j] < a[i]`，则 `a[i..mid]` 均 `≥ a[i] > a[j]`，
  共 `mid − i + 1` 对；用 `a[i] <= a[j]` 优先左半，保证相等元素不计入 `[BOOK] p.38`；
- **溢出**：逆序对最多 `n(n−1)/2`，`n = 5×10^5` 时约 `1.25×10^11`，必须用 `long long` `[DERIVED]`。

### 4.9 奇数码的奇偶性判定（`n` 为奇数）

**不变量：逆序对奇偶性不变** `[DERIVED]`。

1. 空格**左右**移动：排列不变，逆序对数不变；
2. 空格**上下**移动：相当于某个数字在排列中向前/向后移动 `n − 1` 个位置；
   因为它跨过的 `n − 1` 个数字都与它比较一次，逆序对数的变化量等于「跨过的数中比它大/小的个数」，
   而 `n` 为奇数 ⇒ `n − 1` 为偶数 ⇒ **变化量为偶数** ⇒ 奇偶性不变。

**充分性** `[DERIVED]`（书中未证，此处给出证明思路）：
`n` 为奇数时，空格上下移动不改变奇偶性，而通过一系列移动可以把任意三个数字轮换
（3-循环），3-循环是偶置换，故在固定空格位置后可达的排列恰为偶置换类；
两个局面若奇偶性相同，可先把空格移到同一位置，再用 3-循环互相转化。
完整的可达性证明依赖「15-puzzle 的状态图在两个奇偶类上各自连通」这一经典结论，
本报告只给出证明思路，未做逐条构造 `[DERIVED]`。

> 注：`n` 为偶数时（POJ2893 的 `M×N`），还需把空格所在行计入奇偶性，属扩展内容 `[EXTENSION]`。

### 5.1 离散化 `[BOOK] p.32–33`（已核对 p.42–p.43 图像）

```cpp
void discrete() {
    sort(a + 1, a + n + 1);
    for (int i = 1; i <= n; i++)
        if (i == 1 || a[i] != a[i - 1])
            b[++m] = a[i];
}

int query(int x) {   // x 映射到 1..m
    return lower_bound(b + 1, b + m + 1, x) - b;
}
```

### 5.2 归并排序求逆序对 `[BOOK] p.37–38`（已核对 p.47–p.48 图像）

```cpp
void merge(int l, int mid, int r) {
    int i = l, j = mid + 1;
    for (int k = l; k <= r; k++)
        if (j > r || i <= mid && a[i] <= a[j]) b[k] = a[i++];
        else b[k] = a[j++], cnt += mid - i + 1;
    for (int k = l; k <= r; k++) a[k] = b[k];
}
```

> `cnt` 需为 `long long`；书中此处按 `int` 语境书写，实际题目需注意溢出 `[DERIVED]`。

### 5.3 对顶堆（Running Median）`[DERIVED]`（书中只给规则，未给代码）

```cpp
priority_queue<int> big;                              // 较小的一半（大根堆）
priority_queue<int, vector<int>, greater<int>> small; // 较大的一半（小根堆）

void insert(int x) {
    if (big.empty() || x <= big.top()) big.push(x);
    else small.push(x);
    if (big.size() > small.size() + 1) { small.push(big.top()); big.pop(); }
    if (small.size() > big.size() + 1) { big.push(small.top()); small.pop(); }
}
int median() { return small.size() >= big.size() ? small.top() : big.top(); }
```

### 5.4 快速选择 `[DERIVED]`

```cpp
int kth(int l, int r, int k) {          // 第 k 大，1-based
    if (l == r) return a[l];
    int p = l + rand() % (r - l + 1);
    swap(a[p], a[r]);
    int pivot = a[r], i = l;
    for (int j = l; j < r; j++)
        if (a[j] > pivot) swap(a[i++], a[j]);   // 严格大于进左半
    swap(a[i], a[r]);                            // pivot 落到 i
    int cnt = i - l;                             // 左半（大于 pivot）的个数
    if (k <= cnt) return kth(l, i - 1, k);
    if (k == cnt + 1) return pivot;
    return kth(i + 1, r, k - cnt - 1);
}
```

## 7. 易错点与注意事项

- **离散化后忘记查询用 `lower_bound`**：`query` 必须二分，不能假设下标就是值 `[DERIVED]`。
- **离散化改变了下标含义**：原数组与映射数组不要混用 `[DERIVED]`。
- **环形均分直接套线形公式**：必须先断环并取中位数 `[BOOK] p.35–36`。
- **行列未分别判断整除**：`T % N`、`T % M` 决定最多能满足几个要求 `[DERIVED]`。
- **逆序对计数用 `int`**：`n = 5×10^5` 时答案超 `int`，必须 `long long` `[DERIVED]`。
- **相等元素被计入逆序对**：合并时必须 `a[i] <= a[j]` 优先左半 `[BOOK] p.38`。
- **快速选择递归了两侧**：只递归包含第 `k` 大的一侧，否则退化为快排 `[DERIVED]`。
- **对顶堆用 `int` 存不下**：元素值大时用 `long long` 堆 `[DERIVED]`。
- **奇数码忘记 `n` 为奇数的前提**：`n` 为偶数时判定还需空格行号 `[DERIVED]`。
- **`n` 为偶数用错公式**：POJ2893 属扩展，不在本章原书范围 `[EXTENSION]`。
