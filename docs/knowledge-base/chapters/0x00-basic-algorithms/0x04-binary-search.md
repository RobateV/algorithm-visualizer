## 3. 核心知识点

### 3.1 二分的前提：单调性

- 二分的**基础用法**是在单调序列或单调函数中查找 `[BOOK] p.25`。
- 适用于二分答案时，需要「答案一侧合法、另一侧不合法」的**分段单调性** `[BOOK] p.28`。
- 不具备单调性时，二分没有依据——这是最常见的误用 `[DERIVED]`。

### 3.2 本书统一的整数域写法

- 始终保证**答案位于闭区间 `[l, r]` 内**；循环以 `l == r` 结束 `[BOOK] p.26`。
- 每次的 `mid` 必定归属于左半段或右半段之一；终止时 `l` 就是答案位置 `[BOOK] p.26`。
- 书中评价这种写法「始终保持答案位于二分区间内，二分结束条件对应的值恰好在答案所在位置，还可以很自然地处理无解的情况」`[BOOK] p.26`。

### 3.3 两种配套形式

| 形式 | 适用场景 | 收缩方式 | mid 取法 |
| --- | --- | --- | --- |
| A（后继型） | 找「第一个 ≥ x」 | `r = mid` / `l = mid + 1` | `mid = (l + r) >> 1` |
| B（前驱型） | 找「最后一个 ≤ x」 | `l = mid` / `r = mid - 1` | `mid = (l + r + 1) >> 1` |

- **为什么必须配套**：若 B 误用 `(l + r) >> 1`，当 `r - l = 1` 时 `mid = l`；走 `l = mid` 分支区间不缩小 → **死循环**；走 `r = mid - 1` 分支则 `l > r`，无法以 `l == r` 结束 `[BOOK] p.26`。
- **mid 取值范围**：`(l + r) >> 1` 取不到 `r`；`(l + r + 1) >> 1` 取不到 `l` `[BOOK] p.27`。

### 3.4 无解处理与越界哨兵

- 利用 3.3 的性质，把初始区间扩大以包含一个**越界下标** `[BOOK] p.27`：
  - 后继型：`[1, n]` → `[1, n + 1]`
  - 前驱型：`[1, n]` → `[0, n]`
- 若二分终止在越界下标上，说明数列中不存在所求的数 `[BOOK] p.27`。

**关键实现细节（书中未展开，但代码必须处理）** `[DERIVED]`：

- 模板末尾的 `return a[l]` **只在答案存在时安全**。若 `l` 停在 `n + 1`（后继型无解）或 `0`（前驱型无解），
  直接 `a[l]` 会越界或读到哨兵值。
- 正确做法是先判断下标，再取值：

```cpp
// 后继型，区间 [1, n+1]
int pos = l;
if (pos == n + 1) { /* 无解 */ }
else { int val = a[pos]; }

// 前驱型，区间 [0, n]
int pos = l;
if (pos == 0) { /* 无解 */ }
else { int val = a[pos]; }
```

- 也可以把哨兵 `a[n+1]` 预先赋成 `+∞`、`a[0]` 赋成 `−∞`，让 `return a[l]` 在无解时也返回值，
  但调用方仍需通过下标判断「是否真的找到」`[DERIVED]`。

### 3.5 实数域二分

- **循环条件**：`l + eps < r`（书中写 `l + 1e-5 < r`）；每次按 `mid` 上的判定选择 `r = mid` 或 `l = mid` `[BOOK] p.27`。
- **精度取法**：需保留 k 位小数时，取 `eps = 10^-(k+2)` `[BOOK] p.27`。
- **替代策略**：精度不易确定时，直接**固定循环次数**（书中用 100 次），书中评价其精度通常比设 `eps` 更高 `[BOOK] p.27`。
- **适用范围**：单调函数的求根、单调判定函数的边界值 `[BOOK] p.27`。

### 3.6 三分法

- **单峰函数**：存在唯一极大值点，左侧**严格**单调上升、右侧**严格**单调下降；唯一极小值点者称**单谷函数** `[BOOK] p.28`。
- **做法**：在 `[l, r]` 上取两点 `lmid`、`rmid`，把区间分成三段 `[BOOK] p.28`：
  - 若 `f(lmid) < f(rmid)`：极大值点一定在 `lmid` 右侧，令 `l = lmid`；
  - 若 `f(lmid) > f(rmid)`：极大值点一定在 `rmid` 左侧，令 `r = rmid`。
- **收敛速度**：取三等分点则每次缩小 `1/3`；取二分点两侧极近处则近似缩小 `1/2`；总体仍是 log 级 `[BOOK] p.28`。
- **适用条件（重要）**：书中特别强调「严格」单调性。若存在一段函数值相等，方向判断失效，三分法不再适用 `[BOOK] p.28`。

**`f(lmid) == f(rmid)` 时怎么办** `[BOOK] p.28`：

- 在**严格**单峰（两侧分别严格单调）的前提下，相等的情况可以任选一侧收缩——书中说明此时令 `l = lmid` 或 `r = rmid` 均可；
- 若函数存在**平台段**（不严格单调），相等时无法判断极值在哪一侧，三分法不再适用 `[BOOK] p.28`。
- `[DERIVED]` 实现上，多数严格单峰场景直接按 `else` 分支处理即可；但若题目函数可能有平台，
  必须先确认「严格单峰」这一前提，或改用其他方法。

### 3.7 二分答案：把求解转化为判定

- **抽象**：把可行方案集合视作「定义域」，评估值构成「值域」；设最优值为 `S` `[BOOK] p.28`。
- **单调性论证**：
  - 对任意 `x > S`，不存在合法方案达到 `x` 分（否则与 `S` 的最优性矛盾）；
  - 对任意 `x ≤ S`，一定存在合法方案达到或超过 `x` 分（最优解本身即满足）。
  - 因此值域具有「`S` 一侧合法、另一侧不合法」的分段单调性，可二分找到分界点 `[BOOK] p.28`。
- **典型特征**：题目出现「最大值最小 / 最小值最大」时，往往就是二分答案的信号 `[BOOK] p.29`。

### 3.8 STL 中 `lower_bound` / `upper_bound` 的准确语义

书中提到 `lower_bound` 与 `upper_bound` 实现了「后继」查找 `[BOOK] p.27`。准确区分如下：

| 调用 | 返回值 | 与本章模板的对应 |
| --- | --- | --- |
| `lower_bound(b, e, x)` | 第一个 **≥ x** 的位置 | 后继型 `a[mid] >= x` |
| `upper_bound(b, e, x)` | 第一个 **> x** 的位置 | 不是前驱型 |
| `upper_bound(b, e, x) - 1` | 最后一个 **≤ x** 的位置 | 前驱型，但**必须先检查是否等于 `b`**（不存在时越界） |
| `lower_bound(b, e, x) - 1` | 最后一个 **< x** 的位置 | 同理需检查边界 |

> 易错点：`upper_bound` 本身是「第一个 > x」，**不是**「最后一个 ≤ x」；后者要减 1 并判边界 `[DERIVED]`。

## 4. 算法推导

### 4.1 不变量与正确性

**后继型**（找第一个 `≥ x` 的位置）`[DERIVED]`：

- 不变量：**若答案存在，则它始终落在 `[l, r]` 内**。
- 取 `mid = ⌊(l+r)/2⌋`：
  - 若 `a[mid] ≥ x`，则 `mid` 及其右侧**都满足条件**；但「第一个满足条件的位置」不可能出现在 `mid` 右侧，
    只能在 `[l, mid]` 内 → `r = mid`（`mid` 本身可能是答案，不能写成 `mid - 1`）；
  - 若 `a[mid] < x`，则 `mid` 及左侧都不满足，答案在 `[mid+1, r]` → `l = mid + 1`。
- 终止 `l == r`，此时 `l` 为答案位置（若存在）`[BOOK] p.26`。
- 单调性保证被排除的那一半**不可能含答案**；闭区间保证 `mid` 本身不会被误排除。

**前驱型**（找最后一个 `≤ x`）对称：`a[mid] ≤ x` 时 `l = mid`，否则 `r = mid - 1`；`mid` 取 `(l+r+1)>>1` `[BOOK] p.26`。

### 4.2 为什么 mid 取法必须配套

设 `r = l + 1` `[DERIVED]`：

| 形式 | mid 取法 | 结果 |
| --- | --- | --- |
| 前驱型 + `(l+r)>>1` | `mid = l` | 若进入 `l = mid` 分支，区间不变 → **死循环**；若进入 `r = mid - 1`，得到 `r = l - 1` → **`l > r`** |
| 后继型 + `(l+r)>>1` | `mid = l` | `r = mid` 可缩小；`l = mid + 1` 可推进 → 正常 |
| 前驱型 + `(l+r+1)>>1` | `mid = r` | `l = mid` 推进、`r = mid - 1` 缩小 → 正常 |
| 后继型 + `(l+r+1)>>1` | `mid = r` | 若 `r = mid` 不变 → **死循环** |

所以「`mid` 向下取整」配「`r = mid`」，「`mid` 向上取整」配「`l = mid`」，两者不可交叉 `[BOOK] p.26, p.27`。

### 4.3 为什么用 `>> 1` 而不是 `/ 2`

- 右移**向下取整**，整数除法**向零取整** `[BOOK] p.26`。
- 当二分值域包含负数时，`/ 2` 会向 0 方向偏，导致区间收缩不符合「向下取整」的推导，可能死循环或漏解 `[BOOK] p.26`。
- `[DERIVED]` 书复制例题的二分值域是 `[0, Σa]`（非负），所以书中那里允许写 `(l + r) / 2`；在可能含负数的场景必须用 `>> 1`。

### 4.4 实数二分的精度

- 每次区间减半，`k` 次后长度 `(r-l)/2^k`；终止条件 `r - l ≤ eps` 时精度约为 `eps` `[DERIVED]`。
- `eps = 10^-(k+2)` 的理由：给浮点误差与输出四舍五入留两位余量 `[DERIVED]`（书中只给出结论）。
- 固定 100 次：区间长度变为原来的 `2^-100`，远小于常见 `eps`，故精度通常更高 `[BOOK] p.27`。
- 注意：固定次数是**迭代次数**，不是精度保证；若初始区间极大，100 次后仍未达到要求的情形理论上存在 `[DERIVED]`。

### 4.5 三分法为什么能排除一侧

对单峰函数（唯一极大值点 `x*`）`[DERIVED]`：

- 若 `f(lmid) < f(rmid)`：
  - 情形 1：两点都在 `x*` 左侧（函数严格递增），则 `x* > rmid > lmid`；
  - 情形 2：两点分居 `x*` 两侧，则 `x* > lmid`。
  - 两种情形都有 `x* > lmid`，故可令 `l = lmid`，不会丢掉极值点。
- 若 `f(lmid) > f(rmid)`：对称地 `x* < rmid`，令 `r = rmid`。
- **严格性**：若存在平台段，`f(lmid) = f(rmid)` 时既可能极值在左、也可能在右，无法判断方向 `[BOOK] p.28`。
- **相等时**：严格单峰下可任取一侧（`l = lmid` 或 `r = rmid` 都不会丢极值点）`[BOOK] p.28`；
  存在平台段时方向不确定，书中明确三分法不适用 `[BOOK] p.28`。
- `[DERIVED]` 求单谷（极小值）时不等号方向反过来：`f(lmid) > f(rmid)` 时 `l = lmid`，否则 `r = rmid`。

### 4.6 书复制问题（二分答案）

**题意**：把 `N` 本书分成**连续**的 `M` 组，使「厚度之和最大的一组」的厚度 `T` 最小 `[BOOK] p.28–29`。

- **判定**：给定 `size`，问能否分成不超过 `M` 组且每组之和 `≤ size` `[BOOK] p.29`。
- **单调性**：`size` 越大越容易可行；书中用最优值 `S` 论证：若每组要求 `< S`，则 `M` 组装不下，需更多组 → 不可行；若允许 `> S`，则存在方案使组数不超过 `M` `[BOOK] p.29`。
- **贪心最少组数**：顺序扫描，能装就装，装不下就开新组。因为书必须**连续**分组，任何分组方案的第 `k` 组都从某个位置开始，贪心让当前组尽量多装，组数不会比任何方案更多 `[DERIVED]`（归纳：贪心的第 `k` 组右端点不早于任意方案的右端点）。
- **二分范围**：`l = 0`、`r = Σ a_i` `[BOOK] p.29`（上界取总和必然可行）。

**⚠ 书中 `valid()` 有一个实现漏洞** `[DERIVED]`：

书中 `valid(int size)` 没有检查「单本书厚度 > size」的情况。此时 `rest = size - a[i]` 变成负数，
后续书只能不断新开组，但只要总组数仍 `≤ m`，函数就返回 `true`——然而那本超厚的书所在的组
**已经违反了「每组厚度之和 ≤ size」的约束**。

最小反例：`a = [5, 9, 4]`、`m = 3`。

| 版本 | 返回值 | 是否可行 |
| --- | --- | --- |
| 书中原版 `valid` | `5` | ❌ 真实最优是 `9`（三组各一本，最大 9） |
| 补上 `if (a[i] > size) return false;` | `9` | ✅ |

两种等价修法（任选其一）：

1. 在 `valid` 开头或循环内加 `if (a[i] > size) return false;`；
2. 把二分下界设为 `l = max(a_i)`（此时 `size` 永远不小于任何一本书）。

本报告 §5.4 给出修正版；原书代码按原样保留在 §5.4 上方，便于对照 `[BOOK] p.29`。

### 4.7 Best Cow Fences（POJ2018）

**题意**：给定正整数数列 `A`，求平均数最大、长度不小于 `L` 的连续子段 `[BOOK] p.29`。

1. **判定转化**：「是否存在长度 ≥ L、平均数 ≥ mid 的子段」。
   把每个数减去 `mid`，等价于「是否存在长度 ≥ L、子段和 ≥ 0 的子段」`[BOOK] p.29`。
2. **前缀和**：令 `sum[i] = A[1] + … + A[i]`（减去 `mid` 之后），则
   `max_{i-j ≥ L}(A[j+1..i]) = max_{L ≤ i ≤ N}(sum[i] − min_{0 ≤ j ≤ i−L} sum[j])` `[BOOK] p.30`。
3. **只维护一个最小值**：随 `i` 增大，`j` 的范围只增加一个元素，故用一个变量维护 `min{sum[j]}`，
   每次与 `sum[i−L]` 取 `min` 即可 `[BOOK] p.30`。
4. **为什么是 O(N)**：每个 `i` 只做常数次比较，`min_val` 单调不增，无需回头枚举 `j` `[BOOK] p.30`。
5. **判定与收缩**：若最大子段和 `≥ 0`，说明 `mid` 可行，`l = mid`；否则 `r = mid` `[BOOK] p.31`。
6. **输出**：`cout << int(r * 1000) << endl;`——题目要求输出平均数的 1000 倍整数部分 `[BOOK] p.31`。
7. **为什么长度不小于 L**：题目限定；若去掉限制，就是经典最大子段和（Kadane），书中以 POJ1050 作练习 `[BOOK] p.30`。

**⚠ 输出精度问题（原书代码的已知缺陷）** `[DERIVED]`

原书用 `eps = 1e-5`、区间 `[-1e6, 1e6]`，最后输出 `int(r * 1000)`。
二分结束时 `r` 与真实最优平均数 `A*` 之间仍有约 `eps` 量级的误差；
当 `1000·A*` 非常接近整数时，`r·1000` 可能**跨过整数边界**，输出比正确答案大 1。

可复现反例（本轮实机运行）：

| 项目 | 值 |
| --- | --- |
| `N = L = 99999` | 前 100 个数为 1，后 99899 个数为 2 |
| 真实平均数 | `199898 / 99999` |
| 正确输出 | `floor(1000 × 平均) = 1998` |
| 原书代码输出 | `r ≈ 1.999003870878` → `int(r × 1000) = 1999`（多 1） |

**整数化修正** `[DERIVED]`：不再依赖浮点截断，直接二分整数 `q`。

- **判定**：`valid(q)` ⇔ 存在长度 ≥ L 的子段，使 `1000·Σa − q·len ≥ 0`。
  令 `b_i = 1000·a_i − q`，判定等价于「存在长度 ≥ L 的子段和非负」，可用前缀和 + 最小前缀在 `O(N)` 完成。
- **等价性**：`Σ(1000·a_i − q) / len ≥ 0 ⇔ 1000·avg ≥ q`，
  所以 `valid(q)` 恰表示「存在子段其平均数的 1000 倍 ≥ q」。
- **单调性**：`q` 增大时每个 `b_i` 减小，子段和单调不增，故 `valid` 关于 `q` 单调（真→假），可二分。
- **范围**：`a_i ≤ 2000` ⇒ `1000·avg ≤ 2000000`，二分 `[0, 2000000]`。
- **取最大可行 q**：用上取整 `mid = (lo + hi + 1) / 2`，`valid(mid)` 为真则 `lo = mid`，否则 `hi = mid - 1`。
- **复杂度**：`O(N log 2×10^6) ≈ O(21N)`，空间 `O(N)`；前缀和用 `long long` 防溢出。
- **实测**：上述反例输出 `1998`，与 `floor(1000 × 平均)` 一致。

### 4.8 Innovative Business（AcWing113）

**题意**：`N` 个元素，任意两元素的大小关系确定且**不具有传递性**；每次提问只能得知某两个元素的关系，
要求在不超过 10000 次提问内把它们排成一行，使每个元素都小于右边相邻元素，`N ≤ 1000` `[BOOK] p.31`。

**1. 竞赛图与 Hamilton 路径** `[DERIVED]`

把元素看作点，任两点之间由大小关系确定一条有向边，得到一个**竞赛图**（完全有向图）。
书末脚注指出：任意竞赛图都存在 **Hamilton 路径** `[BOOK] p.31`，所以合法排列一定存在。

> 注意区分：
> - **Hamilton 路径**只要求「相邻两点有边且方向一致」，**不要求全序**；
> - **全序排列**要求任意两元素可比且传递，本题的关系**不具传递性**，一般不存在全序。
> 因此不能把本算法解释为「在已排序数组上二分」。

**2. 增量构造与边界不变量** `[BOOK] p.31` + `[DERIVED]`

归纳假设：前 `k−1` 个元素已排成 `a[1], a[2], …, a[k−1]`，且相邻关系成立。
现在把第 `k` 个元素 `x` 插入其中某处。

引入两个**虚拟边界**：`a[0] = −∞`、`a[k] = +∞`（只用于推理，不参与实际比较）。
定义

```
P(i) = [ x < a[i] ]        (1 ≤ i ≤ k−1)
P(0) = 0                   （x 一定大于 −∞）
P(k) = 1                   （x 一定小于 +∞）
```

插入位置 `l` 合法的充要条件是：`P(l−1) = 0` 且 `P(l) = 1`，
即 `a[l−1] < x < a[l]`。

**二分维护的不变量**：

```
P(l−1) = 0,   P(r) = 1      初始 l = 1, r = k
```

每步取 `mid = ⌊(l+r)/2⌋`（`l ≤ mid < r`）：

- 若 `P(mid) = 1`，令 `r = mid`（右端仍为 1，左端不变）；
- 若 `P(mid) = 0`，令 `l = mid + 1`（左端变为 0，右端不变）。

终止时 `l == r`，由不变量得 `P(l−1) = 0`、`P(l) = 1`，即 `a[l−1] < x < a[l]`，
插入后新的两对相邻关系都成立，其余相邻关系未变。

**3. 关键：不需要 P 单调** `[DERIVED]`

这里**不要求** `P(1..k−1)` 单调。二分只依赖两个端点分别被钉死为 0 和 1：

- 只要 `P(l−1)=0` 且 `P(r)=1`，且每次收缩保持这个性质，
  区间长度严格递减，最终必收缩到 `l=r`；
- 由于 `P` 在两端取值不同，中间必然存在一个位置使 `P` 由 0 变 1（离散介值），
  该位置就是合法插入点。

这正是本算法能在**非传递**关系上工作的原因；书中的「继续往前比较」证明说的也是同一件事 `[BOOK] p.31`。

**4. 每次询问确实把区间缩小** `[DERIVED]`

设当前长度 `len = r − l + 1`，`mid = ⌊(l+r)/2⌋`：

- `P(mid)=1` 时新区间 `[l, mid]`，长度 `mid − l + 1 ≤ (len+1)/2`；
- `P(mid)=0` 时新区间 `[mid+1, r]`，长度 `r − mid ≤ len/2`。

两种情况都至少缩小约一半，故每次插入至多 `⌈log₂ k⌉` 次询问。
累计 `Σ_{k=2}^{N} ⌈log₂ k⌉`；`N = 1000` 时为 **8977** 次（本轮实测计算），小于题目限制 10000 `[DERIVED]`。

**5. 与普通二分的区别** `[DERIVED]`

| 项目 | 普通二分 | 本题 |
| --- | --- | --- |
| 前提 | 序列有序（P 单调） | **不需要** P 单调 |
| 依据 | 单调性排除一半 | 两端固定为 0/1，离散介值 |
| 结果 | 找到相等元素 | 找到 0→1 的转变位置 |

**修正版**（补上「单本厚度超过 size 直接失败」与下界 `max(a_i)`）`[DERIVED]`：

```cpp
bool valid(int size, const vector<int>& a, int n, int m) {
    for (int i = 1; i <= n; i++) if (a[i] > size) return false;   // 关键修正
    int group = 1, rest = size;
    for (int i = 1; i <= n; i++) {
        if (rest >= a[i]) rest -= a[i];
        else group++, rest = size - a[i];
    }
    return group <= m;
}

int main() {
    int mx = 0, sum = 0;
    for (int i = 1; i <= n; i++) { mx = max(mx, a[i]); sum += a[i]; }
    int l = mx, r = sum;                 // 下界取 max(a_i) 也等价
    while (l < r) {
        int mid = (l + r) / 2;
        if (valid(mid, a, n, m)) r = mid; else l = mid + 1;
    }
    cout << l << endl;
}
```

### 5.5 Best Cow Fences `[BOOK] p.30–31`（已核对 p.40–41 图像）

```cpp
double a[100001], b[100001], sum[100001];

int main() {
    int N, L; cin >> N >> L;
    for (int i = 1; i <= N; i++) scanf("%lf", &a[i]);
    double eps = 1e-5;
    double l = -1e6, r = 1e6;
    while (r - l > eps) {
        double mid = (l + r) / 2;
        for (int i = 1; i <= N; i++) b[i] = a[i] - mid;
        for (int i = 1; i <= N; i++) sum[i] = (sum[i - 1] + b[i]);

        double ans = -1e10;
        double min_val = 1e10;
        for (int i = L; i <= N; i++) {
            min_val = min(min_val, sum[i - L]);
            ans = max(ans, sum[i] - min_val);
        }
        if (ans >= 0) l = mid; else r = mid;
    }
    cout << int(r * 1000) << endl;
}
```

**整数化实现** `[DERIVED]`（解决 §4.7 的截断问题，不依赖浮点）：

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

// 是否存在长度 >= L 的子段，使 1000*sum - q*len >= 0
bool validQ(const vector<ll>& a1000, int N, int L, ll q) {
    vector<ll> s(N + 1, 0);
    for (int i = 1; i <= N; i++) s[i] = s[i - 1] + a1000[i] - q;
    ll mn = LLONG_MAX;
    for (int i = L; i <= N; i++) {
        mn = min(mn, s[i - L]);
        if (s[i] - mn >= 0) return true;
    }
    return false;
}

ll solve(const vector<ll>& a1000, int N, int L) {
    ll lo = 0, hi = 2000000;                 // a_i <= 2000 => 1000*avg <= 2e6
    while (lo < hi) {
        ll mid = (lo + hi + 1) / 2;          // 上取整：找最大可行 q
        if (validQ(a1000, N, L, mid)) lo = mid; else hi = mid - 1;
    }
    return lo;
}
```

- 输入用 `a1000[i] = 1000LL * a[i]`，全程 `long long`；
- 结果 `lo = floor(1000 × 最大平均数)`，与题目要求的输出一致；
- 复杂度 `O(N log 2×10^6)`。

## 7. 易错点与注意事项

- **mid 取法与收缩方式混用**：`r - l = 1` 时死循环或 `l > r` `[BOOK] p.26`。
- **收缩时漏掉 mid**：后继型写 `r = mid - 1`、前驱型写 `l = mid + 1` 会丢解 `[BOOK] p.27`。
- **无解时直接 `return a[l]`**：`l` 可能等于 `n + 1` 或 `0`，**数组越界** `[DERIVED]`。
- **负数值域用 `/ 2`**：向零取整，与向下取整不一致 `[BOOK] p.26`。
- **实数精度**：`eps` 与保留位数不匹配；固定次数并非「精度保证」 `[BOOK] p.27`。
- **三分用在非严格单峰函数上**：存在平台段时方向判断失效 `[BOOK] p.28`。
- **二分答案前提没验证**：判定函数必须关于答案单调；书中让读者自己思考 Best Cow Fences 的单调性 `[BOOK] p.30`。
- **书复制忘记「连续」限制**：分组必须连续，不能排序后任意划分 `[BOOK] p.29`。
- **书复制漏判「单本厚度 > size」**：书中原版 `valid` 会给出过小的答案（见 §4.6 反例）`[DERIVED]`。
- **Best Cow Fences 输出格式**：题目要求 1000 倍整数部分，`int(r * 1000)` `[BOOK] p.31`。
- **误把 Innovative Business 当普通有序数组二分**：其正确性依赖边界不变量与归纳构造（见 §4.8）`[DERIVED]`。
