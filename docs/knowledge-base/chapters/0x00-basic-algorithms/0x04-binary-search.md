- **为什么需要**：书中指出，答案具有单调性时，二分可把求解转化为判定；依据复杂度理论，判定的难度小于求解，因此二分的适用范围很广 `[BOOK] p.25`。

## 3. 核心知识点

### 3.1 二分的前提：单调性

- **定义**：序列或函数在讨论范围内具有单调性，即「一侧合法、另一侧不合法」的分界结构。
- **核心思想**：利用单调性，一次比较即可排除整段区间。
- **适用问题**：有序序列查找、单调函数求根、答案空间可判定且单调的最优化问题。
- **来源**：`[BOOK] p.25`

### 3.2 本书统一的整数域二分写法

- **形式**：始终保证答案位于**闭区间** `[l, r]` 内；循环以 `l = r` 结束；每次的 `mid` 必定归属于左半段或右半段之一 `[BOOK] p.26`。
- **性质**：终止时 `l` 的值就是答案所在位置（若答案存在）。
- **来源**：`[BOOK] p.26`

### 3.3 两种配套形式

| 形式 | 适用场景 | 收缩方式 | mid 取法 |
| --- | --- | --- | --- |
| A（后继型） | 找「第一个 ≥ x」 | `r = mid` / `l = mid + 1` | `mid = (l + r) >> 1` |
| B（前驱型） | 找「最后一个 ≤ x」 | `l = mid` / `r = mid - 1` | `mid = (l + r + 1) >> 1` |

- **为什么必须配套**：若形式 B 误用 `mid = (l + r) >> 1`，当 `r - l = 1` 时 `mid = l`；进入 `l = mid` 分支则区间不缩小造成**死循环**；进入 `r = mid - 1` 分支则 `l > r`，循环无法以 `l = r` 结束 `[BOOK] p.26`。
- **mid 取值范围的性质**：`(l + r) >> 1` 取不到 `r`；`(l + r + 1) >> 1` 取不到 `l` `[BOOK] p.27`。

### 3.4 无解处理

- 利用 3.3 的性质，把初始区间扩大以包含一个**越界下标**：
  - 后继型：[1, n] → `[1, n + 1]`
  - 前驱型：[1, n] → `[0, n]`
- 若二分终止在越界下标上，说明数列中不存在所求的数 `[BOOK] p.27`。

### 3.5 实数域二分

- **循环条件**：`l + eps < r`；每次按 `mid` 上的判定选择 `r = mid` 或 `l = mid`。
- **精度取法**：需保留 k 位小数时，取 `eps = 10^-(k+2)` `[BOOK] p.27`。
- **替代策略**：精度不易确定时，直接**固定循环次数**，书中评价其精度通常比设 `eps` 更高 `[BOOK] p.27`。

### 3.6 三分法求单峰函数极值

- **单峰函数**：存在唯一极大值点，左侧严格单调上升、右侧严格单调下降；唯一极小值点者称**单谷函数** `[BOOK] p.28`。
- **做法**：在定义域 `[l, r]` 上取两点 `lmid`、`rmid`，把函数分成三段：
  - 若 `f(lmid) < f(rmid)`，极大值点一定在 `lmid` 右侧，令 `l = lmid`；
  - 若 `f(lmid) > f(rmid)`，极大值点一定在 `rmid` 左侧，令 `r = rmid` `[BOOK] p.28`。
- **收敛速度**：取三等分点则每次缩小 1/3；取二分点两侧极近处则近似缩小 1/2；总体仍是 log 级 `[BOOK] p.28`。
- **适用条件（重要）**：书中特别强调「严格」单调性；若存在一段函数值相等，则无法判断边界如何缩小，三分法不再适用 `[BOOK] p.28`。

### 3.7 二分答案：把求解转化为判定

- **结构**：把可行方案集合视作「定义域」，其评估值构成「值域」；设最优值为 S。
- **单调性论证**：
  - 对任意 `x > S`，不存在合法方案达到 `x` 分（否则与 S 的最优性矛盾）；
  - 对任意 `x ≤ S`，一定存在合法方案达到或超过 `x` 分（最优解本身即满足）。
  - 因此值域具有「S 一侧合法、另一侧不合法」的分段单调性，可二分找到分界点 `[BOOK] p.28`。
- **转化结果**：求最优解 → 判定「是否存在可行方案评分达到 mid」`[BOOK] p.28`。
- **典型特征**：题目出现「最大值最小 / 最小值最大」时，往往就是可用二分答案的信号 `[BOOK] p.29`。

## 4. 算法推导

### 4.1 后继型为什么是 `r = mid`

1. 目标：在单调递增序列中找第一个 `≥ x` 的位置。
2. 取中点 `mid`，比较 `a[mid]` 与 `x`。
3. 若 `a[mid] ≥ x`：由单调性，`mid` 之后的数都更大，不可能出现更早的「第一个 ≥ x」，因此可行区间缩到左半段。
4. 关键：`mid` 本身也可能是答案，所以取 `r = mid` 而不是 `mid - 1`。
5. 若 `a[mid] < x`：`mid` 及其左侧都不满足，取 `l = mid + 1`。
6. 终止时 `l = r` 即答案位置 `[BOOK] p.26`。

### 4.2 前驱型为什么是 `l = mid`

1. 目标：找最后一个 `≤ x` 的位置。
2. 若 `a[mid] ≤ x`：`mid` 之前的数都更小，不可能是「最后一个」，可行区间缩到右半段；`mid` 也可能是答案，取 `l = mid`。
3. 若 `a[mid] > x`：取 `r = mid - 1` `[BOOK] p.26`。

### 4.3 为什么用 `>> 1` 而不是 `/ 2`

- 右移运算**向下取整**，整数除法**向零取整**；
- 当二分值域包含负数时，`/ 2` 不能正常工作 `[BOOK] p.26`。

### 4.4 三分法的判定依据

- 对单峰函数，若 `f(lmid) < f(rmid)`：两点要么同在极大值点左侧（单调上升段），要么分居极大值点两侧；无论哪种，极大值点都在 `lmid` 右侧 `[BOOK] p.28`。
- 证明的关键是「严格单调」，否则相等段会让方向判断失效 `[BOOK] p.28`。

### 4.5 其他写法的取舍（书中评价）

- 本书写法的优点：答案始终位于二分区间内，结束条件对应的值恰好在答案位置，还能自然地处理无解，形式优美 `[BOOK] p.27`。
- 缺点：由两种形式共同组成，需要针对具体问题选择 `[BOOK] p.27`。
- 其他写法（如 `l = mid + 1, r = mid - 1` 或 `l = r = mid`）虽可避免两种形式，但会**丢失 mid 点上的答案**、结束时可行区间未缩到确切答案，需要额外处理 `[BOOK] p.27`。

## 5. 代码实现

> 以下两段为书中模板，已对照页面图像逐字符核对（PDF p36 / 印刷 p26）。

**后继型（第一个 ≥ x）** `[BOOK] p.26`

```cpp
while (l < r) {
    int mid = (l + r) >> 1;
    if (a[mid] >= x) r = mid; else l = mid + 1;
}
return a[l];
```

**前驱型（最后一个 ≤ x）** `[BOOK] p.26`

```cpp
while (l < r) {
    int mid = (l + r + 1) >> 1;
    if (a[mid] <= x) l = mid; else r = mid - 1;
}
return a[l];
```

**实数域二分（eps 版）** `[BOOK] p.27`（**已逐字符核对页面图像**）

```cpp
while (l + 1e-5 < r) {
    double mid = (l + r) / 2;
    if (calc(mid)) r = mid; else l = mid;
}
```

**实数域二分（固定次数版）** `[BOOK] p.27`（已核对 p.37–p.38 跨页代码）

```cpp
for (int i = 0; i < 100; i++) {
    double mid = (l + r) / 2;
    if (calc(mid)) r = mid; else l = mid;
}
```

> 书中说明：固定次数得到的精度通常比设置 `eps` 更高 `[BOOK] p.27`。
> 实试（`sqrt(10)`，区间 [0,10]）：eps 版误差 `1.47e-6`（< 1e-5），固定 100 次误差 `0`，与书中说法一致。

- **关键变量**：`l`、`r` 为闭区间端点；`mid` 为中点；`x` 为查找目标。
- **边界处理**：初始区间需覆盖所有可能答案；无解时用越界下标（见 3.4）。
- **复杂度**：时间 `O(log n)`，空间 `O(1)` `[DERIVED]`（依据：每次区间减半）。
- **常见实现错误**：两种形式混用 mid 取法；收缩写成 `mid ± 1` 时漏掉答案；用 `/ 2` 处理负数。

## 7. 易错点与注意事项

- **mid 取法必须与收缩形式配套**，否则 `r - l = 1` 时死循环或越界 `[BOOK] p.26`。
- **收缩时忘记 `mid` 也可能是答案**：后继型写成 `r = mid - 1`、前驱型写成 `l = mid + 1` 会漏解 `[BOOK] p.27`。
- **无解处理**：不扩展越界下标时，终止位置可能落在合法区间外，需要额外判断 `[BOOK] p.27`。
- **负数与除法**：`/ 2` 向零取整，负数场景出错 `[BOOK] p.26`。
- **实数精度**：`eps` 与保留位数要匹配（`10^-(k+2)`）；固定次数的结果通常更稳 `[BOOK] p.27`。
- **三分的前提**：函数必须严格单调（无相等段），否则不适用 `[BOOK] p.28`。
- **二分答案的前提**：判定函数必须关于答案单调；书中在 Best Cow Fences 处特意让读者自己思考「为什么该问题的答案具有单调性」`[BOOK] p.30`。

## 9. 教学应用建议

> 本节为教学设计建议，**非原书内容** `[EXTENSION]`（设计层面）。

- **PPT 式讲解**：按 3.1 → 3.2 → 3.3 → 3.7 的顺序推进，先建立「区间始终包含答案」的不变量，再引入两种形式。
- **适合动画**：闭区间 `[l, r]` 的收缩；`mid` 落点；淘汰区间的淡出；后继型与前驱型在同一数组上的**对比**。
- **适合交互**：让学生猜下一步 `l`/`r` 往哪边走；拖动 `mid` 观察区间变化。
- **适合可视化的状态**：`l`、`r`、`mid` 三个指针；当前区间；比较结果（`<`、`=`、`>`）。
- **代码同步行**：`while (l < r)`、`mid = (l + r) >> 1`、`r = mid`、`l = mid + 1`。
- **课堂问题**：为什么 `r = mid` 而不是 `mid - 1`？如果两种 mid 取法混用会怎样？
- **互动实验**：给定 `[1,2,2,2,4,6,6,8]`，让 lower_bound 与 upper_bound 分别跑一遍，比较返回值（2 与 5）与相等元素个数（5−2）。

> 与本节的 3.2 / 3.3 对应；其区间为左闭右开 `[l, r)`，与书中闭区间写法**不同**，
