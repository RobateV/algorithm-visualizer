## 2. 本章定位

- **解决什么问题**：把「反复求区间和」与「反复对区间做加减」这两类高频操作，从每次 `O(n)` 降到 `O(1)`（查询）或「两次单点」 (修改) `[BOOK] p.21–22`。
- **为什么需要**：书中指出前缀和是「通过递推能求出的基本信息之一」，而部分和可以表示为前缀和相减 `[BOOK] p.21`。
- **与前后知识的联系**：
  - 前：`0x02 递推与递归`——前缀和本身就是一维递推（`S[i] = S[i-1] + A[i]`）`[BOOK] p.21`。
  - 后：`0x37 容斥原理`——二维前缀和的两个公式「蕴含的思想其实就是容斥原理」`[BOOK] p.23`。
  - 后：`0x63 树的直径与最近公共祖先`——「在 0x63 节，我们还会继续探讨差分技巧在树上的应用」`[BOOK] p.23`。
  - 后：`0x04 二分`——Best Cow Fences 的判定用到「区间和 = 前缀和相减」，是本章的直接应用 `[DERIVED]`（依据：0x04 文档 p.30 记录）。
  - 旁：`0x42 树状数组`——用 `lowbit` 维护前缀和，解决「带修改的前缀和」`[DERIVED]`（书中未在本章提及）。
- **前置知识（书中体现）**：数组下标、循环、递推 `[BOOK] p.21`。
- **前置知识（整理者建议）**：能画出一维数轴上的区间与端点 `[MY-NOTE]`。

## 3. 核心知识点

### 3.1 一维前缀和

定义 `[BOOK] p.21`：

```
S[i] = Σ_{j=1..i} A[j]        （S[0] = 0）
```

递推：`S[i] = S[i-1] + A[i]`。

**区间和** `[BOOK] p.22`：

```
sum(l, r) = Σ_{i=l..r} A[i] = S[r] - S[l-1]
```

- 前缀和是**静态**结构：建表 `O(n)`，每次查询 `O(1)`，但**不支持修改**（修改需重建）。
- `[MY-NOTE]` 这也解释了它和「差分」的分工：前缀和擅长「多次查」，差分擅长「多次改」。

### 3.2 二维前缀和

定义 `[BOOK] p.22`：

```
S[i,j] = Σ_{x=1..i} Σ_{y=1..j} A[x,y]
```

递推（容斥）`[BOOK] p.22`：

```
S[i,j] = S[i-1,j] + S[i,j-1] - S[i-1,j-1] + A[i,j]
```

边长 R 的正方形和 `[BOOK] p.22`：

```
Σ_{x=i-R+1..i} Σ_{y=j-R+1..j} A[x,y]
  = S[i,j] - S[i-R,j] - S[i,j-R] + S[i-R,j-R]
```

- 一般矩形 `(x1,y1)-(x2,y2)` 的公式同理平移 `[DERIVED]`：

```
sum = S[x2,y2] - S[x1-1,y2] - S[x2,y1-1] + S[x1-1,y1-1]
```

- 建表 `O(nm)`，单次矩形查询 `O(1)` `[BOOK] p.22`。

### 3.3 差分

定义 `[BOOK] p.23`：

```
B[1] = A[1]
B[i] = A[i] - A[i-1]   (2 ≤ i ≤ n)
```

**互逆性** `[BOOK] p.23`：

- 差分序列 `B` 的前缀和就是原序列 `A`；
- 原序列前缀和 `S` 的差分序列也是原序列 `A`。

**区间加转端点** `[BOOK] p.23`：把 `A[l..r]` 全部加 `d`，等价于

```
B[l] += d
B[r+1] -= d
```

其余位置不变。书中强调：这能把「区间操作」转化为「单点操作」`[BOOK] p.23`。

### 3.4 前缀和与差分的关系

| 方向 | 操作 | 结果 |
| --- | --- | --- |
| 差分 → 前缀和 | `B` 做前缀和 | 得到 `A` |
| 前缀和 → 差分 | `S` 做差分 | 得到 `A` |
| 区间加 → 差分 | `B[l]+=d, B[r+1]-=d` | 两次单点修改 |

`[MY-NOTE]` 一句话概括：**前缀和把「区间查询」变成两次减法，差分把「区间修改」变成两次加法**；两者互为逆运算，都建立在同一个递推思想上。

### 3.5 二维差分（原书本章未涉及）

`[DERIVED]` 原书 0x03 只讲了一维差分，二维差分是自然推广，本报告补充但明确标注**非原书内容**。

对矩形 `(x1,y1)-(x2,y2)` 整体加 `d`：

```
D[x1,   y1  ] += d
D[x2+1, y1  ] -= d
D[x1,   y2+1] -= d
D[x2+1, y2+1] += d
```

再对 `D` 求二维前缀和即得修改后的 `A`。四个角的符号是「+ − − +」，与二维前缀和的容斥符号「+ − − +」同源 `[MY-NOTE]`。

### 3.6 边界与下标

- 书中公式统一使用 **1 起始**下标，`S[0] = 0`、`B[0]` 不用 `[BOOK] p.21–23`。
- 差分修改会用到 `B[r+1]`，因此数组要开到 `n+2`；当 `r = n` 时 `B[n+1]` 是**哨兵**，只写不读 `[DERIVED]`。
- 二维前缀和要处理 `i-1`、`j-1` 为 0 的情形，通常把下标整体 +1 平移 `[MY-NOTE]`。
- `0x03` 例题「激光炸弹」的坐标是 0..5000，转成公式用的 1 起始需要 +1 `[BOOK] p.22` 与 `[MY-NOTE]`。

### 3.7 数据规模与溢出

| 场景 | 风险 | 建议 |
| --- | --- | --- |
| 一维前缀和 | `n × max(A)` 可能超 `int` | `long long` `[MY-NOTE]` |
| 二维前缀和 | `n·m × max(A)` 更易溢出 | `long long` `[MY-NOTE]` |
| 激光炸弹 | 网格 5001×5001，价值累加 | 数组与累加用 `long long` `[MY-NOTE]` |
| Tallest Cow | `H ≤ 10^6`，`C[i] ≤ 0` | `int` 足够 `[BOOK] p.24` |

## 4. 算法推导

### 4.1 为什么 `sum(l,r) = S[r] − S[l−1]`

`S[r]` 包含 `A[1..r]`，`S[l−1]` 包含 `A[1..l−1]`，两者相减即 `A[l..r]`（裂项相消）`[DERIVED]`。
关键是 `S[0] = 0` 这个哨兵：当 `l = 1` 时公式仍然成立，无需特判 `[MY-NOTE]`。

### 4.2 为什么二维递推要「加一次、减两次」

`S[i−1,j]` 与 `S[i,j−1]` 都覆盖了左上角的 `S[i−1,j−1]`，相加会把它算两遍，因此减掉一次；最后补上 `A[i,j]` `[DERIVED]`。
正方形和公式同理：大矩形 `S[i,j]` 减去上方与左方两条，被多减的左上角加回来 `[DERIVED]`。
书中把这两个式子蕴含的思想直接点名为「容斥原理」`[BOOK] p.23`。

### 4.3 为什么差分能把区间加变成端点操作

设 `A[l..r]` 全部 `+d`，观察相邻差 `B[i] = A[i] − A[i−1]` `[DERIVED]`：

- `i = l`：`A[l]` 变大而 `A[l−1]` 不变 → `B[l]` 增加 `d`；
- `l < i ≤ r`：`A[i]` 与 `A[i−1]` 同时变大 → 差值不变；
- `i = r+1`：`A[r]` 变大而 `A[r+1]` 不变 → `B[r+1]` 减少 `d`；
- 其余位置不受影响。

所以只有两个端点的差分值改变。反过来，对 `B` 做一次前缀和就能还原修改后的 `A`，这就是「差分 + 前缀和」的完整闭环 `[BOOK] p.23`。

### 4.4 IncDec Sequence 的结论

题意：每次选区间 `[l,r]` 全体 +1 或 −1，求让所有数相等的最少操作数与最终序列种类 `[BOOK] p.23–24`。

设差分 `b`（`b[1]=a[1]`，`b[i]=a[i]−a[i−1]`），令 `b[n+1] = 0`。一次区间操作等价于**在 `b[1..n+1]` 中选两个数，一个 +1、一个 −1** `[BOOK] p.23`。

目标：把 `b[2..n]` 变成全零，此时整个序列变成 `n` 个相同的 `b[1]` `[BOOK] p.23`。

记 `b[2..n]` 中正数之和为 `p`、负数绝对值之和为 `q` `[BOOK] p.24`。

**下界**：每次操作最多让正数总和减少 1（它只对其中一个位置 −1），所以至少 `p` 次；同理至少 `q` 次。故 `≥ max(p,q)` `[DERIVED]`。

**构造**：

1. 正负配对（第 1 类）：可执行 `min(p,q)` 次；
2. 剩余 `|p−q|` 个未配对，每次与 `b[1]` 或 `b[n+1]` 配对（第 2、3 类），共 `|p−q|` 次 `[BOOK] p.24`。

合计 `min(p,q) + |p−q| = max(p,q)`，与下界吻合，故最优 `[BOOK] p.24`。

**方案数**：第 2、3 类操作在 `|p−q|` 次中选择用 `b[1]` 还是 `b[n+1]`，能产生 `|p−q| + 1` 种不同的 `b[1]`，即最终序列有 `|p−q| + 1` 种 `[BOOK] p.24`。

> 第 4 类「同时选 `b[1]` 与 `b[n+1]`」不改变 `b[2..n]`，书中明确指出没有意义 `[BOOK] p.24`。

### 4.5 Tallest Cow 的建模

已知最高的牛是第 `P` 头、身高 `H`，另有 `M` 对「可互相看见」的关系 `[BOOK] p.24`。

- 一对关系 `(A_i, B_i)`（设 `A_i < B_i`）意味着中间的牛**至少比它们矮 1**；
- 用数组 `C` 记录「相对最高牛的降幅」：`C[A_i+1 .. B_i−1]` 全部减 1 `[BOOK] p.24`；
- `C[P]` 必为 0（`P` 是最高的），最终 `height[i] = H + C[i]` `[BOOK] p.24`。

朴素做法 `O(NM)`；用差分 `D`：`D[A_i+1] -= 1`、`D[B_i] += 1`，再对 `D` 求前缀和得到 `C`，复杂度降到 `O(N+M)` `[BOOK] p.24`。

> 书中特别提醒：`(A_i, B_i)` 可能重复输入，重复关系只处理一次 `[BOOK] p.24`。

## 5. 代码实现

> 原书 0x03 **没有给出代码块**（正文只有公式、图示与文字说明）。
> 以下实现均为整理者按书中公式重构 `[DERIVED]`，不是原书代码。

### 5.1 一维前缀和与区间查询

```cpp
int n;
long long A[N], S[N];          // S[0] = 0
for (int i = 1; i <= n; i++) S[i] = S[i - 1] + A[i];
long long sum(int l, int r) { return S[r] - S[l - 1]; }
```

- `O(n)` 预处理，`O(1)` 查询；`S` 用 `long long` 防溢出 `[MY-NOTE]`。

### 5.2 二维前缀和

```cpp
long long S[N][N];
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
        S[i][j] = S[i-1][j] + S[i][j-1] - S[i-1][j-1] + A[i][j];

// 正方形 (i,j) 为右下角、边长 R
long long square(int i, int j, int R) {
    return S[i][j] - S[i-R][j] - S[i][j-R] + S[i-R][j-R];
}
// 一般矩形 (x1,y1)-(x2,y2)
long long rect(int x1, int y1, int x2, int y2) {
    return S[x2][y2] - S[x1-1][y2] - S[x2][y1-1] + S[x1-1][y1-1];
}
```

### 5.3 一维差分与区间修改

```cpp
long long B[N + 2];            // 多开一格放 B[n+1] 哨兵
void range_add(int l, int r, long long d) {
    B[l] += d;
    B[r + 1] -= d;
}
// 还原：前缀和
for (int i = 1; i <= n; i++) { B[i] += B[i - 1]; A[i] += B[i]; }
```

### 5.4 IncDec Sequence 的结论实现

```cpp
long long p = 0, q = 0;
for (int i = 2; i <= n; i++) {
    long long d = a[i] - a[i - 1];
    if (d > 0) p += d; else q -= d;
}
long long minOps = max(p, q);        // 最少操作次数
long long kinds  = llabs(p - q) + 1; // 最终序列种类
```

### 5.5 Tallest Cow

```cpp
// 对每对 (A,B)，A<B：D[A+1]--, D[B]++
// 需要 set<pair<int,int>> 去重
for (int i = 1; i <= n; i++) C[i] = C[i - 1] + D[i];
for (int i = 1; i <= n; i++) printf("%d\n", H + C[i]);
```

- 复杂度 `O(N + M)` `[BOOK] p.24`。

### 5.6 复杂度汇总

| 结构 | 预处理 | 单次查询/修改 | 空间 |
| --- | --- | --- | --- |
| 一维前缀和 | `O(n)` | 查询 `O(1)` | `O(n)` |
| 二维前缀和 | `O(nm)` | 矩形查询 `O(1)` | `O(nm)` |
| 一维差分 | `O(n)` | 区间加 `O(1)` | `O(n)` |
| 差分还原 | 前缀和 `O(n)` | — | `O(n)` |

## 7. 易错点与注意事项

- **区间和写成 `S[r] − S[l]`**：漏掉 `l` 本身，正确是 `S[r] − S[l−1]` `[DERIVED]`。
- **忘记 `S[0] = 0`**：导致 `l = 1` 时越界或特判 `[MY-NOTE]`。
- **二维前缀和符号写错**：顺序必须是「+ 上 + 左 − 左上 + 自己」`[BOOK] p.22`。
- **二维查询越界**：`i−R`、`j−R` 可能为负，要么整体平移下标，要么先判 `R` 与边界 `[MY-NOTE]`。
- **差分数组开小**：`r+1` 可达 `n+1`，需要多开一格 `[DERIVED]`。
- **差分还原方向错**：还原是**前缀和**（`B[i] += B[i−1]`），不是再差分 `[BOOK] p.23`。
- **重复关系未去重**：Tallest Cow 中同一对 `(A_i,B_i)` 多次出现会重复减 1，必须去重 `[BOOK] p.24`。
- **`R` 大于地图边长**：激光炸弹中 `R` 可能超过 5000，需要截断到边界 `[MY-NOTE]`；书中未展开此细节，标 `[?]`。
- **`long long` 使用不足**：前缀和累加极易溢出 `int` `[MY-NOTE]`。
- **混淆「前缀和数组」与「原数组」**：`S` 是累加结果，`A` 才是原值；差分场景下 `B` 是差，`A` 才是原值 `[MY-NOTE]`。

## 9. 教学应用建议

> 以下为教学设计建议，**非原书内容** `[MY-NOTE]`。

- **PPT 式讲解**：先讲「静态查询」再讲「动态修改」，用同一个数组对比两种结构的分工。
- **适合动画**：
  1. 前缀和累加过程：`S[i]` 逐个吞并 `A[i]`；
  2. 区间和 = 两条前缀和相减（用两条水平条的重叠/相减表示）；
  3. 二维容斥：四个矩形「加、加、减、补」的叠色演示；
  4. 差分打标记：`+d` 与 `−d` 两个箭头，前缀和后变成一段「台阶」。
- **学生最易误解的点**：
  - 以为差分数组就是原数组；
  - 以为修改后要重建前缀和；
  - 二维符号顺序记反；
  - `S[l]` 与 `S[l−1]` 搞混。
- **值得动态展示的状态**：`i` 指针、`S[i]` 数值、`B[l]`/`B[r+1]` 两个端点、还原后的 `A` 段。
- **交互式例题设计**：
  - 给定数组，让学生拖动 `l`、`r`，实时显示 `S[r]−S[l−1]`；
  - 给若干「区间 +d」操作，让学生先在差分数组上点两个端点，再看还原结果；
  - 二维：点击矩形四角，观察 `+ − − +` 的符号。
- **代码同步**：高亮 `S[i] = S[i-1] + A[i]`、`B[l] += d`、`B[r+1] -= d`、`C[i] = C[i-1] + D[i]`。
