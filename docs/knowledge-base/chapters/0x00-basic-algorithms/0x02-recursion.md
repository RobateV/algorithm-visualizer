## 3. 核心知识点

### 3.1 状态空间与两种遍历方式

- **状态空间**：一个实际问题的各种可能情况构成的集合；程序运行就是对状态空间的遍历 `[BOOK] p.11`。
- 算法与数据结构通过**划分、归纳、提取、抽象**提高遍历效率 `[BOOK] p.11`。
- **递推与递归是遍历状态空间的两种基本方式** `[BOOK] p.11`。

### 3.2 递推与递归的区别

| 方式 | 起点 | 方向 | 书中表述 |
| --- | --- | --- | --- |
| 递推 | 已知的「问题边界」 | 正向推导到原问题 | 「以已知的问题边界为起点向原问题正向推导」`[BOOK] p.11` |
| 递归 | 原问题 | 寻找缩小路线，再反向回溯 | 「以原问题为起点尝试寻找把状态空间缩小到已知的问题边界的路线，再通过该路线反向回溯」`[BOOK] p.11` |

两者共同的**前提**：原问题与问题边界之间的每一步变换具有**相似性**，即每步面对的都是同一类子问题，仅在规模或限制上不同，可以用「求解原问题的程序」来求解 `[BOOK] p.12`。

### 3.3 递归的三个操作

1. **缩小**：在「原问题 → 问题边界」的变换路线上向前走一步，缩小状态空间规模 `[BOOK] p.12`。
2. **求解**：对缩小后的问题调用同一程序；结果可能成功，也可能失败 `[BOOK] p.12`。
3. **扩展**：若成功，把子问题的答案扩展为当前问题的答案；若失败，回到当前问题，继续尝试其它变换路线，直至确定无解 `[BOOK] p.12`。

两个关键点 `[BOOK] p.12`：

- **自身调用自身**：子问题被视为新的「原问题」，由同一段程序求解。
- **回溯时还原现场**：把当前问题缩小为子问题时，所有对当前状态的修改在返回后都必须失效。

### 3.4 为什么必须还原现场

递归体的基本单元是「缩小 → 求解 → 扩展」。横向看，每一层是一次递归体执行；纵向看，左右分别是「寻找路线」与「沿路线推导」`[BOOK] p.13`。

为保证每层的「缩小」与「扩展」能衔接在**同一形式**的问题上，「求解」操作必须保证执行前后程序面对的问题状态相同——这就是还原现场的必要性 `[BOOK] p.13`。

### 3.5 枚举形式与遍历方式

书中按状态空间规模给出常见枚举形式 `[BOOK] p.13`：

| 枚举形式 | 状态空间规模 | 一般遍历方式 |
| --- | --- | --- |
| 多项式 | n^k，k 为常数 | 循环（for）、递推 |
| 指数 | `2^n` | 递归、位运算 |
| 排列 | n! | 递归、C++ `next_permutation` |
| （组合） | C(n,m) | 递归 + 剪枝 |

> 表中「组合」一行为整理者依据本节例题补充 `[DERIVED]`；书中表格原文列出的是多项式、指数、排列三类。

### 3.6 剪枝

- 寻找变换路线的过程就是「搜索」；若能**及时确定当前问题一定无解**，就不必到达问题边界才返回 `[BOOK] p.14`。
- 组合型枚举的剪枝条件：已选超过 m 个，或即使把剩余全部选上也不足 m 个，即可立即返回 `[BOOK] p.14`。
- 效果：方案数从 `2^n` 降为 `C(n,m)` `[BOOK] p.15`；若计入输出，完整生成时间为 `O(n·C(n,m))` `[DERIVED]`。

### 3.7 分治

- **定义**：把一个问题划分为若干规模更小的同类子问题，递归求解，再在回溯时由子问题的解推导原问题的解 `[BOOK] p.17`。
- 与普通递归的差别在于：分治强调「划分」和「合并」，而递归只是遍历方式 `[DERIVED]`。

### 3.8 分形

- 分形是「通过一定规律无限包含自身」的图形 `[BOOK] p.18`。
- N 级城市由四座 N−1 级城市组成，其中左上顺时针旋转 90 度、左下逆时针旋转 90 度；首尾相接后，左上与左下的房屋编号顺序各发生「水平翻转」`[BOOK] p.18`。

### 3.9 栈、堆与存储期

书中给出的模型 `[BOOK] p.19–p.20`：

- 典型 32 位计算机用**堆栈结构**实现函数调用：参数依次入栈，`call` 指令把返回地址入栈并跳转；`ret` 指令把返回地址出栈并跳回 `[BOOK] p.19`。
- 局部变量随 `call`/`ret` 在栈中保存与复原；作用域超过函数的变量与 `new`/`malloc` 分配的空间位于**堆**（与二叉堆不是同一概念）`[BOOK] p.20`。
- 两条推论：
  1. 局部变量每层递归各占一份空间，声明过多或递归过深会**栈溢出** `[BOOK] p.20`；
  2. 非局部变量各层共享同一份空间，必须及时维护、**还原现场** `[BOOK] p.20`。

现代 C++ 的准确说法 `[DERIVED]`（超出原书简化模型）：

| 存储期 | 典型对象 | 位置 |
| --- | --- | --- |
| 自动存储期 | 普通局部变量、函数参数 | 栈（实现细节，标准未规定） |
| 静态存储期 | **全局变量、`static` 局部变量、`static` 成员** | 静态存储区，**不属于堆** |
| 动态存储期 | `new` / `malloc` 分配的对象 | 堆（free store） |
| 线程存储期 | `thread_local` 对象 | 线程局部存储 |

要点：书中「非局部变量」在实现上通常位于**静态存储区**，而不是堆；把全局变量说成「在堆上」是常见误读 `[DERIVED]`。递归中「共享同一份空间」的根因是**静态存储期**，不是堆。

### 3.10 递归转非递归

- 方法：用数组模拟栈，用变量模拟栈指针与返回值，用 `switch/case` 或 `goto/label` 模拟语句跳转 `[BOOK] p.20`。
- 书中以「非递归实现组合型枚举」为例给出改写 `[BOOK] p.20`。

## 4. 算法推导

### 4.1 指数型枚举的递归结构

1. 问题：从 1..n 中任选若干个数，输出所有方案，共 `2^n` 种 `[BOOK] p.14`。
2. 观察：每个数只有「选」与「不选」两种状态。
3. 设计：`calc(x)` 表示「已经决定前 x−1 个数，正在决定第 x 个」。
4. 每层做两次自调用：先「不选 x」再「选 x」，把待定数量减 1，转化为规模更小的同类问题 `[BOOK] p.14`。
5. 边界：`x == n + 1` 时输出当前选择并返回 `[BOOK] p.14`。
6. 正确性：每层恰好覆盖「选/不选」两条分支，且互不重叠，故穷尽 `2^n` 种方案 `[DERIVED]`。
7. 复杂度：递归树节点数 `O(2^n)`；若计入每个方案输出 n 个数，总时间 `O(n·2^n)`；递归深度 `O(n)` `[DERIVED]`。

### 4.2 组合型枚举的剪枝为什么成立

- 若已选数量 `> m`，之后只会越选越多，必然不合法 `[BOOK] p.14`。
- 若「已选 + 剩余可选」仍 `< m`，则无论怎么选都凑不满 m 个，当前分支一定无解 `[BOOK] p.14`。
- 两条判据都在进入分支时即可判断，因此能在到达边界前剪掉整棵子树 `[DERIVED]`。
- 复杂度：剪枝后搜索到的方案恰为 `C(n,m)` 个（每个方案对应一次到边界的成功路径）；若计入输出，总时间 `O(n·C(n,m))` `[DERIVED]`。

### 4.3 排列型枚举

1. 问题：把 1..n 排成一行，输出所有次序，共 `n!` 种 `[BOOK] p.15`。
2. 设 `calc(k)` 表示「已排好前 k−1 位，正在决定第 k 位」。
3. 每层枚举一个尚未使用的数放到第 k 位，标记后递归，返回时清除标记 `[BOOK] p.15`。
4. 边界 `k == n + 1` 时输出整个排列 `[BOOK] p.15`。
5. 复杂度：方案数 `n!`；每个叶子输出 n 个数，总时间 `O(n·n!)`；递归深度 `O(n)` `[DERIVED]`。

### 4.4 费解的开关：为什么只需枚举第一行

书中给出三条性质 `[BOOK] p.16`：

1. 每个位置至多被点击一次（点两次等价于没点）`[BOOK] p.16`。
2. 固定第一行后，满足题意的点击方案**至多一种**：因为第 i 行某位为 1 时，只有点击第 i+1 行对应位置才能把它变成 0，自上而下归纳即得 `[BOOK] p.16`。
3. 点击的先后顺序不影响最终结果 `[BOOK] p.16`。

于是枚举第一行的 32 种点击方式（`2^5`），其余各行由递推唯一确定；最后检查第 5 行是否全 0 即可 `[BOOK] p.16`。32 种覆盖了整个状态空间，故做法正确 `[BOOK] p.16`。

### 4.5 四塔 Hanoi 的递推

- 三塔经典问题：`d[n] = 2 * d[n-1] + 1`（先把前 n−1 个移到 B，再把第 n 个移到 C，最后把前 n−1 个移到 C）`[BOOK] p.16`。
- 四塔问题：设 `f[n]` 为最少步数，则

  ```
  f[n] = min{ 2 * f[i] + d[n-i] },  1 ≤ i < n,  f[1] = 1
  ```

  含义：先把 i 个盘子在四塔模式下移到 B，再把 n−i 个盘子在**三塔**模式下移到 D，最后把 i 个盘子在四塔模式下移到 D `[BOOK] p.16`。
- 对时间复杂度可接受的范围，该做法可推广到 m 塔 `[BOOK] p.16`。

### 4.6 分治求等比数列和

- 目标：`S(p, c) = 1 + p + p^2 + … + p^c`，边界 `S(p, 0) = 1` `[BOOK] p.17`。
- 动机：直接套等比数列公式需要除法，而答案要对 9901 取模，`mod` 只对加、减、乘有分配率，不能先取模再除 `[BOOK] p.17`。

**书中给出的递推** `[BOOK] p.17`（已对照页面图像核对）：

- c 为奇数：`S(p, c) = (1 + p^((c+1)/2)) * S(p, (c-1)/2)`
- c 为偶数：`S(p, c) = (1 + p^(c/2)) * S(p, c/2 - 1) + p^c`

**等价的另一写法** `[DERIVED]`（设 c = 2m，展开合并同类项可得）：

```
S(p, 2m) = p^m + (1 + p^(m+1)) * S(p, m-1)
```

两种写法都正确，书中采用的是前一种。

**数值验证**：

| 例子 | 直接计算 | 书中偶数式 | 等价式 |
| --- | --- | --- | --- |
| p=2, c=2（偶） | 1+2+4 = 7 | (1+2)·S(2,0)+4 = 3+4 = **7** | 2+(1+4)·S(2,0) = 2+5 = **7** |
| p=2, c=3（奇） | 1+2+4+8 = 15 | (1+2²)·S(2,1) = 5·3 = **15** | — |

- 每层规模减半，配合快速幂，`O(log c)` `[BOOK] p.17`。
- 实现时 `S(p,0)=1` 必须显式处理，否则偶数分支的 `c/2 - 1` 会取到 −1 `[DERIVED]`。

### 4.7 分形坐标变换

- 目标：求编号 M 的房屋在 N 级城市中的位置，记为 `calc(N, M)` `[BOOK] p.18`。
- N 级城市由四座 N−1 级城市组成，先递归求 `calc(N-1, M mod 2^(2N-2))` 得到 `(x, y)`，再按 M 落在哪一座做变换 `[BOOK] p.19`：
  - 左上：顺时针旋转 90° 后水平翻转，坐标变为 `(y, x)` `[BOOK] p.19`；
  - 右上：`(x, y + 2^(N-1))` `[BOOK] p.19`；
  - 右下：`(x + 2^(N-1), y + 2^(N-1))` `[BOOK] p.19`；
  - 左下：逆时针旋转 90° 再水平翻转，并对行号加偏移 `[BOOK] p.19`。

> 左下的精确式子 OCR 受损（行号 `2*len - 1`、列号 `len - y - 1` 一带有缺字），标记为**待目视复核**，见 §10。

## 5. 代码实现

### 5.1 递归实现指数型枚举 `[BOOK] p.14`（**已逐字符核对页面图像**）

```cpp
vector<int> chosen; // 被选择的数
void calc(int x) {
    if (x == n + 1) { // 问题边界
        for (int i = 0; i < chosen.size(); i++)
            printf("%d ", chosen[i]);
        puts("");
        return;
    }
    // “不选 x” 分支
    calc(x + 1); // 求解子问题
    // “选 x” 分支
    chosen.push_back(x); // 记录 x 已被选择
    calc(x + 1); // 求解子问题
    chosen.pop_back(); // 准备回溯到上一问题之前，还原现场
}
int main() {
    calc(1); // 主函数中的调用入口
}
```

- 关键点：`push_back` 与 `pop_back` 成对出现，保证回溯后 `chosen` 恢复原状 `[BOOK] p.14`。
- 复杂度：递归树节点数 `O(2^n)`；若计入每个方案输出 n 个数，总时间 `O(n·2^n)`；空间 `O(n)`（递归栈 + chosen）`[DERIVED]`。
- 数组长度：书中用 `vector` 存选择，容量随 n 增长；后面的排列型用定长 `order[20]` 是因为该题限定 `n < 10` `[BOOK] p.15`。

### 5.2 组合型枚举的剪枝 `[BOOK] p.14`（已核对页面图像）

```cpp
if (chosen.size() > m || chosen.size() + (n - x + 1) < m) {
    return;
}
```

- 放在 `calc` 函数开头；`n - x + 1` 是「从 x 到 n 还能选多少个数」`[BOOK] p.14`。

### 5.3 递归实现排列型枚举 `[BOOK] p.15`（**已逐字符核对页面图像**）

```cpp
int order[20]; // 按顺序依次记录被选择的整数
bool chosen[20]; // 标记被选择的整数
void calc(int k) {
    if (k == n + 1) { // 问题边界
        for (int i = 1; i <= n; i++)
            printf("%d ", order[i]);
        puts("");
        return;
    }
    for (int i = 1; i <= n; i++) {
        if (chosen[i]) continue;
        order[k] = i;
        chosen[i] = 1;
        calc(k + 1);
        chosen[i] = 0;
        order[k] = 0; // 这一行可以省略
    }
}
int main() {
    calc(1); // 主函数中的调用入口
}
```

- 数组长度：`order[20]`、`chosen[20]` 对应题目 `n < 10`；下标从 1 用到 n，故 20 足够 `[BOOK] p.15`。
- `order[k] = 0;` 一行书中注明「可以省略」`[BOOK] p.15`。

### 5.4 非递归实现组合型枚举 `[BOOK] p.20–p.21`（**已逐字符核对页面图像，跨两页**）

```cpp
vector<int> chosen;
int stack[100010], top = 0, address = 0, n, m;
void call(int x, int ret_addr) { // 模拟计算机汇编指令 call
    int old_top = top;
    stack[++top] = x; // 参数 x
    stack[++top] = ret_addr; // 返回地址标号
    stack[++top] = old_top; // 在栈顶记录以前的 top 值
}
int ret() { // 模拟计算机汇编指令 ret
    int ret_addr = stack[top - 1];
    top = stack[top]; // 恢复以前的 top 值
    return ret_addr;
}

int main() {
    cin >> n >> m;
    call(1, 0); // calc(1)
    while (top) {
        int x = stack[top - 2]; // 获取参数
        switch (address) {
        case 0:
            if (chosen.size() > m || chosen.size() + (n - x + 1) < m) {
                address = ret(); // return
                continue;
            }
            if (x == n + 1) {
                for (int i = 0; i < chosen.size(); i++)
                    printf("%d ", chosen[i]);
                puts("");
                address = ret(); // return
                continue;
            }
            call(x + 1, 1); // 相当于 calc(x+1)，返回后会从 case 1 继续
            address = 0;
            continue; // 回到 while 循环开头，相当于开始新的递归
        case 1:
            chosen.push_back(x);
            call(x + 1, 2); // 相当于 calc(x+1)，返回后会从 case 2 继续
            address = 0;
            continue; // 回到 while 循环开头，相当于开始新的递归
        case 2:
            chosen.pop_back();
            address = ret(); // 相当于原 calc 函数结尾，执行 return
        }
    }
}
```

- 对应关系：`case 0` ↔ 函数开头（含剪枝与边界），`case 1` ↔ 选 x 后继续，`case 2` ↔ 回溯弹出。
- `stack[top-2]` 取参数、`stack[top-1]` 取返回地址、`stack[top]` 存旧的 `top`，三格一组。
- 书中为简化只给出 `int` 版本的栈与地址；这是示意实现，不是通用递归转换器 `[DERIVED]`。

## 7. 易错点与注意事项

- **忘记还原现场**：非局部变量在递归各层共享，回溯前不恢复会导致后续分支读到脏数据 `[BOOK] p.13, p.20`。
- **递归过深**：局部变量每层各占一份栈空间，容易栈溢出 `[BOOK] p.20`；本节例题 n 都限制在 20 以内 `[BOOK] p.14–15`。
- **边界写错**：`x == n + 1` 才是边界，写成 `x == n` 会漏掉最后一个数的分支 `[DERIVED]`。
- **剪枝条件写反**：`chosen.size() + (n - x + 1) < m` 用的是「剩余可选数量」，漏掉 `+1` 会少算一个数 `[DERIVED]`。
- **模意义下做除法**：等比数列求和不能先取模再除，必须改分治 `[BOOK] p.17`。
- **分形变换方向**：左上、左下分别对应顺/逆时针旋转后再水平翻转，方向搞反会导致坐标镜像 `[BOOK] p.18–19`。
- **混淆「堆」与「二叉堆」**：书中特别提示二者是不同概念 `[BOOK] p.20`。

## 9. 教学应用建议

> 教学设计建议，**非原书内容** `[EXTENSION]`。

- **PPT 式讲解**：先讲「状态空间」这一统一视角，再用「边界 → 原问题」的方向差引出递推与递归。
- **适合动画**：递归调用树（横向前进、纵向回溯）；`call`/`ret` 的栈帧进出；分形逐级生成。
- **适合交互**：让学生手动展开 `calc(3)` 的两次自调用，观察 `chosen` 的变化与还原。
- **适合可视化的状态**：当前递归深度、栈内容、`chosen` 数组、已走路径。
- **代码同步行**：`calc(x + 1)`、`chosen.push_back(x)`、`chosen.pop_back()`。
- **课堂问题**：为什么「不选」分支要写在前面？如果去掉 `pop_back()` 会发生什么？
- **互动实验**：把指数型枚举的剪枝去掉，对比 `n = 15` 时的运行次数差异。
