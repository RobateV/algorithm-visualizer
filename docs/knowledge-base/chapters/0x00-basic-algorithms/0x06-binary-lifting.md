## 2. 本章定位

- **解决什么问题**：当状态空间很大、线性递推无法满足时空要求时，只递推**在 2 的整数次幂位置上**的值，
  再用「任意整数可表示为若干 2 的幂之和」拼出所需值 `[BOOK] p.39`。
- **书中的说法**：使用倍增要求「递推的问题的状态空间关于 2 的次幂具有可划分性」`[BOOK] p.39`。
- **与前后知识的联系**：
  - 前：`0x01 位运算`、快速幂——书中指出「快速幂其实就是『倍增』与『二进制划分』思想的一种体现」`[BOOK] p.39`。
  - 前：`0x03 前缀和`——序列倍增查找用前缀和做区间和判定 `[BOOK] p.40`。
  - 后：`0x63 树的直径与最近公共祖先`——树上倍增（LCA）在该节 `[BOOK] p.39`。
  - 旁：`0x04 二分`——同样是「快速定位」，但倍增在答案为 0/很小时更优 `[BOOK] p.40`。
- **算法前提**：前缀和、比较与循环 `[BOOK] p.40`。
- **学习准备建议**：能手写 ST 表并理解「重叠区间取最值」`[EXTENSION]`。

## 3. 核心知识点

### 3.1 倍增的思想本质

- **为什么需要**：线性递推的空间/时间与状态空间成正比；倍增只算 `2^0, 2^1, 2^2, …` 这些代表位置，
  把复杂度降到对数级 `[BOOK] p.39`。
- **与二进制划分的关系**：任意整数 `k` 可拆成若干个 2 的幂之和，于是「拼」出任意位置的值 `[BOOK] p.39`。
- **成倍扩张 vs 二进制组合**：扩张是「当前长度翻倍」（`p *= 2`），组合是「把若干个 2 的幂拼起来」；
  两者结合才构成倍增算法 `[DERIVED]`。
- **适用条件**：状态可按长度 2 的幂划分并合并（ST 的区间最大值、倍增查找的前缀和） `[BOOK] p.39`。
- **与二分、快速幂的联系** `[DERIVED]`：
  - 快速幂：底数不断平方（成倍扩张）+ 指数按二进制拆分累乘；
  - 二分：每次折半缩小区间，依赖单调性；
  - 倍增：从当前位置「试着跳 2^j 步」，可行就跳、不可行就减半步长——依赖**可加/可合并**且**单调**的判定。

### 3.2 序列前缀和的倍增查找

**模型** `[BOOK] p.39–40`：给定长度 `N` 的数列 `A`（`0 ≤ T ≤ ΣA`），在线回答若干询问：
求最大的 `k`，使 `Σ_{i=1..k} A[i] ≤ T`。

**朴素**：从前向后枚举，每次 `O(N)`；**二分**：预处理前缀和 `O(N)`，每次 `O(log N)`，
但当 `T` 很小时答案 `k` 很小，二分「第一步就检验很长的区间」，反而不如暴力 `[BOOK] p.40`。

**倍增做法** `[BOOK] p.40`：

```
p = 1, k = 0, sum = 0
while p > 0:
    if k + p ≤ N 且 sum + S[k+p] − S[k] ≤ T:
        sum += S[k+p] − S[k]
        k += p
        p *= 2
    else:
        p /= 2
# 此时 k 就是答案
```

- `p` 是当前试探的跨度（总是 2 的幂）；
- `k` 是已确认可行的最远位置；
- `sum` 是 `A[1..k]` 的和（即 `S[k]`），用 `sum + S[k+p] − S[k]` 常数时间判定 `[BOOK] p.40`。
- **不变量** `[DERIVED]`：循环中始终有 `sum = S[k]` 且 `Σ_{i=1..k} A[i] ≤ T`；
  `k` 单调不减，`p` 递减到 0 时 `k` 即为最大可行位置。
- **复杂度** `[DERIVED]`：`p` 从 1 开始每次成功翻倍、失败折半，标准二进制计数器分析给出
  `O(log k)` 次判定；**与答案位置的对数有关，与 N 无关**。书中表述为「时间复杂度的级别为答案的对数」`[BOOK] p.40`。

**前提** `[DERIVED]`：

- `A[i] ≥ 0`，否则前缀和不单调、`k` 的最大性不成立；
- 必须检查 `k + p ≤ N`，否则 `S[k+p]` 越界；
- `T` 可达 `ΣA`，`sum` 需用 `long long`。

### 3.3 Genius ACM（CH0601）

**题意** `[BOOK] p.40`：给定数列 `A` 与整数 `T`，把 `A` 分成尽量少的段，
使每段的「校验值」都不超过 `T`。校验值 = 从段中取 `M` 对（不重复用数）使「每对差的平方」之和最大。

**校验值为什么是首尾配对** `[BOOK] p.40`：应取最大的 `M` 个数与最小的 `M` 个数，
最大配最小、次大配次小……这样平方和最大。

**贪心分段** `[BOOK] p.40`：每段在「校验值 ≤ T」的前提下尽量长，从头顺序分段即可得到最少段数。

**倍增找右端点** `[BOOK] p.40`：固定左端点 `L`，令 `p = 1, R = L`；
检验 `[L, R+p]` 的校验值，`≤ T` 则 `R += p, p *= 2`，否则 `p /= 2`；`p = 0` 时 `R` 为最远右端点。

**复杂度** `[BOOK] p.41`：

- 每个左端点最多循环 `O(log N)` 次，每次对 `O(R−L)` 的一段排序，总 `O(N log² N)`；
- 若用「只对新增部分排序再归并」的增量方式，可降到 `O(N log N)`。

**溢出** `[DERIVED]`：差的平方可达 `(10^9)² = 10^18`，`M` 对相加达 `10^18` 量级，
必须用 `long long`（`unsigned long long` 更稳）。

### 3.4 ST 算法

**RMQ 建模** `[BOOK] p.41`：长度 `N` 的数列，在线回答「下标 `l~r` 的最大值」。

**状态** `[BOOK] p.41`：`F[i][j]` 表示从 `i` 开始的 `2^j` 个数的最大值，即区间 `[i, i+2^j−1]`。

**转移** `[BOOK] p.41`：`F[i][j] = max(F[i][j−1], F[i+2^{j−1}][j−1])`，边界 `F[i][0] = A[i]`。

**查询** `[BOOK] p.41`：取 `k = ⌊log₂(r−l+1)⌋`，答案为
`max(F[l][k], F[r−2^k+1][k])`。

**为什么可以重叠** `[BOOK] p.41`：求最大值时，两段只要**覆盖**整个区间即可，重叠不影响结果。
`[DERIVED]` 求和则不成立：重叠部分会被算两次，因此 ST 不能直接用于区间和。

**复杂度** `[BOOK] p.41`：预处理 `O(N log N)`，单次查询 `O(1)`。

**log 的实现** `[BOOK] p.42`：书中直接用 `log(r−l+1)/log(2)`；严格保证 `O(1)` 应预处理
`1..N` 每个长度的 `k`（`O(N)` 时间），避免浮点误差与函数调用开销。

## 4. 算法推导

### 4.1 倍增为什么正确

把答案 `k` 写成二进制 `k = 2^{i_1} + 2^{i_2} + …`（从大到小排列）`[DERIVED]`：
算法从大到小尝试每个 2 的幂，能拼上就拼——这与「二进制拆分」一一对应，
所以最终拼出的 `k` 是**不超过可行上限的最大值**。

### 4.2 倍增查找的不变量与复杂度

- 不变量：`sum = S[k]` 且 `S[k] ≤ T`（`[DERIVED]`，归纳：只在判定成功时更新 `k` 与 `sum`）；
- 终止：`p` 每次失败减半，必到 0；此时不存在更大的可行 `k`（否则其二进制最高位会被尝试并成功）；
- 复杂度：`p` 的取值序列是「翻倍—折半」的二进制计数器，判定次数 `O(log k)` `[DERIVED]`。

### 4.3 校验值首尾配对的正确性

设段内数升序 `x_1 ≤ … ≤ x_n`，取 `M` 对使 `Σ(a−b)²` 最大 `[DERIVED]`：
平方对差值敏感，应让差值尽可能大；把最大与最小配对、次大与次小配对，
任何交换配对都会让某一对的差值减小、且不会让另一对增大（交换论证），故首尾配对最优。

### 4.4 贪心分段的最优性

**引理**：若某方案的第一段右端点 `R' < R`（`R` 为从 1 开始的最远可行右端点），
把它扩展到 `R` 不会使后续段数增加 `[DERIVED]`：剩余部分变短，任何对剩余部分的分段仍可行。
故「每段尽量长」的贪心最优。

### 4.5 ST 查询覆盖性

`k = ⌊log₂ len⌋` ⇒ `2^k ≤ len < 2^{k+1}` `[DERIVED]`：

- 左段 `[l, l+2^k−1]`、右段 `[r−2^k+1, r]`，两段长度都是 `2^k`；
- 左段起点 `l ≤ r−2^k+1`（因为 `len ≥ 2^k`），右段终点 `r ≥ l+2^k−1`，故两段覆盖 `[l,r]`；
- 覆盖即可，重叠无妨（最大值幂等）。

### 4.6 浮点 log 的问题

`log(r−l+1)/log(2)` 在 `r−l+1` 为 2 的幂时可能因浮点误差得到 `k−ε`，向下取整出错 `[DERIVED]`。
稳妥做法是预处理 `lg[len] = ⌊log₂ len⌋`（`lg[i] = lg[i/2] + 1`），查询 `O(1)` 且无误差。

## 5. 代码实现

### 5.1 序列倍增查找 `[DERIVED]`（书中只给流程，未给完整代码）

```cpp
int doublingSearch(const vector<long long>& A, int n, long long T) {
    vector<long long> S(n + 1, 0);
    for (int i = 1; i <= n; i++) S[i] = S[i - 1] + A[i];
    int p = 1, k = 0;
    long long sum = 0;
    while (p > 0) {
        if (k + p <= n && sum + S[k + p] - S[k] <= T) {
            sum += S[k + p] - S[k];
            k += p;
            p *= 2;
        } else {
            p /= 2;
        }
    }
    return k;
}
```

### 5.2 Genius ACM `[DERIVED]`（书中未给完整代码）

```cpp
long long checkValue(vector<long long> v, int M) {   // 首尾配对
    sort(v.begin(), v.end());
    int pairs = min<int>(M, v.size() / 2);
    long long s = 0;
    for (int i = 0; i < pairs; i++) {
        long long d = v[v.size() - 1 - i] - v[i];
        s += d * d;
    }
    return s;
}

int geniusACM(const vector<long long>& A, int n, int M, long long T) {
    int segs = 0, L = 1;
    while (L <= n) {
        int p = 1, R = L - 1;
        while (p > 0) {
            if (R + p <= n) {
                vector<long long> v(A.begin() + L, A.begin() + R + p + 1);
                if (checkValue(v, M) <= T) { R += p; p *= 2; continue; }
            }
            p /= 2;
        }
        segs++; L = R + 1;
    }
    return segs;
}
```

### 5.3 ST 表 `[BOOK] p.41`（已逐字符核对 p.51 图像）

```cpp
void ST_prework() {
    for (int i = 1; i <= n; i++) f[i][0] = a[i];
    int t = log(n) / log(2) + 1;
    for (int j = 1; j < t; j++)
        for (int i = 1; i <= n - (1 << j) + 1; i++)
            f[i][j] = max(f[i][j - 1], f[i + (1 << (j - 1))][j - 1]);
}

int ST_query(int l, int r) {
    int k = log(r - l + 1) / log(2);
    return max(f[l][k], f[r - (1 << k) + 1][k]);
}
```

> 书中提示：为保证严格 `O(1)`，可预处理 `1..N` 每个长度的 `k` 值 `[BOOK] p.42`。

## 7. 易错点与注意事项

- **倍增查找不检查 `k + p ≤ N`**：`S[k+p]` 越界 `[DERIVED]`。
- **把倍增用于非单调/含负数的前缀和**：`k` 的最大性失效 `[DERIVED]`。
- **`p` 初值与终止条件**：`p` 必须从 1 开始、以 `p > 0` 为循环条件，写成 `p >= 1` 且整除会死循环 `[DERIVED]`。
- **Genius ACM 忘记 `M` 对需要 `2M` 个数**：不足时取到不能取为止 `[BOOK] p.40`。
- **平方和溢出**：`(10^9)^2 = 10^18`，必须 `long long` `[DERIVED]`。
- **ST 用于区间和**：重叠会重复计数，不成立 `[DERIVED]`。
- **ST 查询 `k` 取错**：`k` 必须是 `⌊log₂ len⌋`，取大了会越界 `[DERIVED]`。
- **浮点 `log` 误差**：长度恰为 2 的幂时可能少 1，建议预处理整数 log `[DERIVED]`。
- **倍增与二分混淆**：二分依赖单调性折半，倍增依赖「按 2 的幂可合并」`[EXTENSION]`。
