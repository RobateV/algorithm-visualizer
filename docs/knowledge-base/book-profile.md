## 3. 页码体系与换算

书中有三套页码，必须区分：

| 部分 | 印刷页码 | PDF 页码 | 换算 |
| --- | --- | --- | --- |
| 封面 / 版权 | 无 | p1 – p3 | — |
| 前言、致谢 | 1 – 4 | p4 – p7 | PDF = 印刷 + 3 |
| 目录 | 1 – 3 | p8 – p10 | PDF = 印刷 + 7 |
| **正文（0x00 – 0x7F）** | **1 – 488** | **p11 – p498** | **PDF = 印刷 + 10** |

正文换算已用三处独立证据交叉验证：

- p12 页脚印 E2E，p13 页脚印 E3E → 偏移 10
- 目录标注 0x00 起始于印刷 p1，对应 PDF p11
- 附录 0x7F 标注印刷 p473，对应 PDF p483

> 本知识库所有 Esource_pagesE 一律记录**印刷页码**；
> 需要 PDF 页码时按 EPDF = 印刷 + 10E 换算，并在 Esource-map.mdE 复核。

### OCR 已知缺陷（写文档时必须记住）

1. **汉字之间被插入空格**（E基 本 算 法E），检索时需要先归一化。
2. 易混字：E己/已E、E襯/补E、E田相/用相E 等。
3. 行内数学符号经常丢失或错位（E≤E→E<E、E−1E→E一 1E）。
4. 代码块的缩进、符号（E<<E、E>>E、E&E、E|E）不可信，**必须看图**。
5. 页脚页码有时被识别成孤立数字，可能混入正文。
