### 关键决策

- 二次校验以 **重新读 GitHub 评论** 为唯一来源；无 `bodyDigest` 的旧记录一律拒绝（fail-closed）
- 隔离用 `git worktree`（`<项目根>/../.dsh-worktrees/<pr>-<sha12>-<commentId>`），detached 到任务 HEAD
- **加锁顺序：先任务锁后全局锁**——同一任务并发返回 `locked`，不同任务返回 `global-lock-busy`
- DSH 只允许 `--profile headless --json <task>` 一种形态；参数与环境均走白名单，token 不传子进程
- `--execute` 必须显式配 `--mock-dsh` 或 `--allow-real-dsh`，否则拒绝（默认 dry-run）
- 重试硬上限 2 次；连续失败达阈值打开熔断，直到手动 `--resume`
