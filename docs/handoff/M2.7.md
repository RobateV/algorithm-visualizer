## 关键决策

- 授权是**文件 + 改名消费**，不是命令行开关；崩在消费前=没跑，崩在消费后=烧掉授权但不重跑
- `--isolation-confirmed` 是教师的环境确认标记，执行器无法自证隔离；
  worktree 只防污染 Git，不防读宿主机文件
- Mock 成功不等于真实成功：跳过逻辑要求 `status=succeeded` **且** `mode` 相同
- 真实执行仍不 commit / 不 push / 不评论
