## 已完成

  有效期 ≤24h / maxRuns=1），消费即改名，不能复用；`workRoot` 必须是规范化绝对路径且严格一致
- `executor.mjs`：新增 `--real-dsh --grant <file> --isolation-confirmed`；缺任一即拒绝

  锁内**先 reserved 再消费授权**，消费失败保留预留并暂停
- 一次性契约：禁止 commit/push/PR 评论/merge/部署，只允许 `tests/automation-smoke/`；
  执行后本地校验 `HEAD` 与改动路径，越界判失败
- `state`：结果按 `taskKey + mode` 分别持久化，Mock 尝试不消耗真实配额
- 文档：`docs/zh/real-run-isolation.md`、`USAGE.zh.md` §7

## 关键决策

- 授权是**文件 + 改名消费**，不是命令行开关；崩在消费前=没跑，崩在消费后=烧掉授权但不重跑
- `--isolation-confirmed` 是教师的环境确认标记，执行器无法自证隔离；
  worktree 只防污染 Git，不防读宿主机文件
- Mock 成功不等于真实成功：跳过逻辑要求 `status=succeeded` **且** `mode` 相同
- 真实执行仍不 commit / 不 push / 不评论
