## 1. 项目目标

建设面向信息学竞赛教学的算法可视化网页：

- PPT 式原理讲解；
- 算法执行过程动画；
- 动画与代码同步展示；
- 交互式算法体验；
- 教师可修改讲解文字与教学内容；
- 逐步整理《算法竞赛进阶指南》，形成可靠的知识库，为网页课程提供内容基础。

知识库不是摘要。每章需覆盖：核心概念、算法原理、关键性质、适用条件、正确性证明或关键推导、
复杂度、实现细节、易错点、算法联系、教学可视化价值。

**来源标记（当前约定）**：

| 标记 | 含义 |
| --- | --- |
| `[BOOK]` | 原书明确内容（含页码） |
| `[DERIVED]` | 整理者的推导、证明、勘误 |
| `[EXTENSION]` | 原书以外的教学补充或扩展 |

旧文档中的 `[MY-NOTE]` 与 `[?]` 已在 0x04 阶段统一废止；未确认内容改写为「待确认」文字。
不得把推导或猜测伪装成原书结论。

## 7. 关键审查结论与算法修复（按章节）

### 0x03 前缀和与差分

- 书复制/区间加等结论已核对；文档 §5.3 采用「方案 A：B 由原数组建立」，
  强调还原是 `A[i] = B[i]`（不是 `+=`），并给出无修改/单次/多次重叠测试。
- 待复核：p.21 开头、激光炸弹 `W_i` 范围。

### 0x04 二分

- **书复制 `valid()` 缺 `size < a[i]` 判断**：书中代码会把过小 `size` 判为可行
  （`[5,9,4], m=3` 得 5，正确为 9；随机 300 组错 84 组）。文档保留原书代码并给修正版。
- **Best Cow Fences 输出精度**：`int(r*1000)` 可能多 1
  （`N=L=99999` 反例：1999 vs 1998）；给出 `[DERIVED]` 整数化判定
  （`b_i = 1000a_i − q`，二分 `q`，`O(N log 2e6)`）。
- **Innovative Business**：正确性靠边界不变量 `P(l−1)=0, P(r)=1`，**不需要 P 单调**；
  不是「有序数组二分」；`N=1000` 询问上界 `Σ⌈log₂k⌉ = 8977 ≤ 10000`。
- **STL 语义**：`lower_bound` = 第一个 ≥ x；`upper_bound` = 第一个 > x；
  前驱 = `upper_bound−1`（需判边界）；这些精确语义标 `[DERIVED]`。


### 0x05 排序

- 复杂度记号：比较排序下界写 `Ω(n log n)`，快排最坏 `Θ(n²)`、平均/期望 `O(n log n)`。
- 奇数码：原书 p.39 给出判定与必要性；**充分性原书明确未展开**，文档不冒充证明。
- 环形均分：最优偏移由**中位数**决定（反例 `C=[3,3,0]`：最小值偏移 3，中位数 2）；
  用配对不等式严格证明，零流量边由中位数取原元素得到。
- 对顶堆：不变量为大根堆存 `⌊M/2⌋` 小、小根堆存 `⌈M/2⌉` 大、`big.top() ≤ small.top()`；
  只调大小不检查跨堆有序是错误的。
- Quickselect：严格二路划分在全相等时退化为 `Θ(n²)`（实测 1,124,250 次 vs 三路 1,500 次）；
  改为三路划分。
- 奇数码：`n` 为偶数时「逆序对数之差与空格行数之差同奇偶」；朴素 `O(n⁴)` 不可行，
  应摊平后归并/树状数组 `O(n² log n)`。

### 0x06 倍增

- 倍增查找：利用 `sum = S[k]`，判定写 `S[k+p] ≤ T`，避免 `sum + S[k+p]` 中间溢出；
  预处理 `O(N)` 一次、单次查询 `O(log k)`、`k=0` 为 `O(1)`。
- Genius ACM：校验值用 `__int128` 累加 + 超 `T` 提前退出；
  反例（超出原题范围的压力测试）旧实现 1 段、新实现 2 段。
- 首尾配对：用平方和交换不等式证明；并补「区间缩短校验值不增大」的单调性用于贪心。
- ST 表：两段覆盖查询、重叠幂等；不能用于区间和；`log` 建议预处理成整数表。
