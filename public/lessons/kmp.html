💡 前缀函数 π：字符串的自相似指纹

π[i] = P[1..i] 这个前缀里，最长的相等真前后缀的长度。
所谓"真"前后缀——不能等于整个串本身，所以 π[1] 恒为 0。
直觉：把字符串复制一份向右滑动，直到头部和尾部图案完全重合——重合的长度就是 π[i]。
比如 ATAAGA：前 3 个字符 ATA，开头 A = 结尾 A → π[3]=1。
我们将一步步推导出 π = [0, 0, 1, 1, 0, 1]。紫色高亮就是 border 两端。
